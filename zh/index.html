RTX Encore 1.2 · Hub 1.2

在您的 RTX 20、30 或 40 上启用帧生成与 Neural Rendering。

RTX Encore 是一个免费模组，为 GeForce RTX 20、30 和 40 带来最高 X6 的 DLSS 帧生成、Neural Rendering 和更快的 DLSS。RTX Encore Hub 会把它安装到您的游戏中，保持最新，并且随时可以把游戏恢复原状。

XeSS / XeFG：高度实验性。 这部分集成的开发过程非常艰难，也相当折腾 :) 请预期可能出现错误、崩溃、画面伪影，以及不同游戏和图形 API 之间的行为差异。欢迎报告问题：在 RTX Encore Hub 中打开游戏的 健康检查 页面，选择 生成诊断包，检查并移除个人信息后，将诊断压缩包附加到 RTX Encore issue。请注明选择的引擎、图形 API 和请求的倍率。Hub 不会自动上传该压缩包。 报告问题.

Neural Rendering 前后对比

Neural Rendering 是 NVIDIA 的网络，作用于 DLSS 生成的画面：一到四个处理阶段，每个阶段一种风格，支持 HDR。RTX Encore 让它在 RTX 20、30 和 40 上运行，并针对 RTX 30 做了自己的优化。实验性功能，默认关闭。

The Blood of Dawnwalker，2560 × 1440，帧生成 X4，NR 310.9.16 以 1472 × 828 运行。角落的叠加信息显示了代价：关闭 NR 时 181 FPS，开启时 132 FPS。

1.2.0

新的 Intel、共用输入、逐轮 NR 和提供程序策略设置需要已识别的模组 1.2.0-beta.1 或更高版本。旧模组保留其支持的控制项。XeFG 路径仍属实验性，取决于模组、图形 API、游戏和运行库。更高倍率有使用条件；请求的倍率不能证明实际显示的帧数。

Intel 引擎及依赖

搭配 RTX Encore 1.2，可在模组支持的场景中选择 XeSS 重建或 XeFG 帧生成。Hub 会随模组安装并验证 Intel 文件及许可证，在同一操作中备份和还原它们。文件已安装不能证明引擎已激活。

逐轮调整 Neural Rendering

四轮处理中的每一轮都可以调整强度、局部色调、局部结构、皮肤结构和角色遮罩，也可以继承全局设置。强度设为零仍会运行该轮处理，不会消除其计算开销。

HDR 输入与曝光

共用设置 srHdr 和 srAutoExposure 跟随所选重建引擎，默认跟随游戏，需要重启生效。HDR 输入不会开启显示器 HDR，也不会将 SDR 转换为 HDR。

RTX Encore Hub 负责安装

找文件夹、匹配 DLL 版本、保存备份：Hub 都会替您完成，并在动手之前先展示它要做什么。

  1. 找到正确的游戏

    全局搜索可直接打开游戏页面。当可执行文件不确定时，游戏页面会提供候选项并记住您的选择，也可以恢复自动选择。

  2. 更有用的诊断

    健康页面报告帧生成提供程序，以及精确配置准入、未经认证的启发式准入或拒绝。诊断压缩包包含模组文本日志、设置和游戏目录文件列表。分享前请检查内容；Hub 不会自动上传。

  3. 统一安装和还原

    搭配 RTX Encore 1.2，可在模组支持的场景中选择 XeSS 重建或 XeFG 帧生成。Hub 会随模组安装并验证 Intel 文件及许可证，在同一操作中备份和还原它们。文件已安装不能证明引擎已激活。

合适的 NVIDIA 文件

模组支持的最新 DLSS、帧生成和 Streamline，只接受带有效 NVIDIA 签名的文件。

Neural Rendering 的 DLL

nvngx_dlssnr.dll 310.9.16，下载并验证。

每项设置都有说明

用表单编辑 rtx-encore.jsonc，对您的显卡无效的设置会变灰。

启动并验证

观察游戏的第一分钟并说明发生了什么，还可以准备一份用于报告的诊断。

社区配置

按游戏分享的设置，按您的机器排序。实验性，测试较少。

与其他模组和平共处

ReShade、OptiScaler 和 Special K 保留各自的文件名；Hub 会选择游戏真正加载的名称。

安装之前先看清楚

Hub 对一个游戏的说明是根据其文件、您的显卡和驱动推断出来的。这并不保证某项功能在该游戏中可用，也不测量任何性能。

快速开始

  1. 从发布页面下载 RTX-Encore-Hub-Setup-<version>.exe 并运行：它只为您的账户安装。也可以下载无需安装的便携版 .zip。
  2. 在游戏库中打开某个游戏的页面，查看这里能做什么，然后点击安装。
  3. 在健康检查中，启动并验证会检查第一分钟。RTX Encore 发布新版本时，点击全部更新。
