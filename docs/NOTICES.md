Game covers in the documentation appear as part of real application screenshots to illustrate the library interface. They are not distributed here as standalone game-art assets. NVIDIA DLLs and game files are not included in this repository.

The screenshots were captured on 14 October 2026 from the application as released in version 1.0.0-rc.1, in English, French and Simplified Chinese, on a demonstration library of stand-in game folders: the games shown are not installed copies, and what the pages say of them is what the Hub deduces from stand-in files. They show the interface, not verified in-game rendering, compatibility or performance. No installation or restoration was performed in a real game for these captures.
