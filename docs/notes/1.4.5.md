# RTX Encore Hub 1.4.5

- **Frame generation engine:** adds the explicit NVIDIA DLSS-FG choice for compatible native Intel FG games such as Mirage. Game preserves the game's native engine; XeFG retains the existing Intel replacement route. FSR remains native. Restart the game after changing the FG engine.
- **Reflex settings:** adds Game / On / On+Boost and the rendered-frame latency report. The request never lowers the game's mode and is suspended in Dynamic or while XeLL owns latency; lower latency is not guaranteed.
- **Community profile templates:** import and export the new FG/Reflex choices and latency-display setting, with the online validator updated to match. Existing profiles and unrelated settings are preserved.

Use with [RTX Encore 1.4.6](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.6). Compatible runtimes are required. Local automated tests cover settings, profile roundtrips and validation; final Hub binaries have no separate real-game validation.
