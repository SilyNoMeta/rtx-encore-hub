# RTX Encore Hub 1.4.1

- **Intel runtime installation and repair:** updates existing compatible Intel components at their native game locations, including plugin folders, while retaining transactional backups and restoration. Missing components use the managed runtime folder; obsolete managed duplicates are removed when a native destination exists.
- **Zenless Zone Zero:** selects the compatible default proxy for this game and recognizes its installation correctly. Explicit manual proxy choices remain respected. Install [RTX Encore 1.4.3](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.3) for the matching XeFG, menu and Neural Rendering fixes. Keep the game's original Streamline files. Thanks to [@WBW333](https://github.com/WBW333) for the report ([mod #83](https://github.com/SilyNoMeta/rtx-encore/issues/83)).

The maintainer confirmed repair, XeFG, the integrated menu and NR in ZZZ with test builds. Local automated tests cover installation, backup restoration and proxy selection. The final 1.4.1 binaries have no separate in-game qualification; Intel XeSS / XeFG remain experimental.
