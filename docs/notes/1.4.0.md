# RTX Encore Hub 1.4.0

- **Settings for RTX Encore 1.4.0:** choose experimental Pre-SR or default Post-SR placement, use Pre-SR recipes and set an independent model profile for each NR pass. These controls require mod 1.4.0; saving a choice does not establish that the game uses it.
- **NR comparison reports:** open the Image and performance lab in game to collect measurements and captures, export them, then import the JSON report into the Hub. The Hub shows NR/SR timing and separate memory counters; unavailable measurements remain unavailable.
- **Qualified comparisons:** relative results require matching observed game conditions and a qualified SR/FG viewport association. Older or unqualified reports remain readable but are not declared comparable. Current native routes without that association provide individual observations, not relative gains. Sequential captures do not establish temporal stability, and global memory changes do not prove savings caused by Pre-SR.

Install RTX Encore 1.4.0 separately for the native menu languages, About tab, DLSS-G control fixes and NR lab. Post-SR remains the default. Pre-SR, its new multipass paths and comparison instrumentation have no GPU or in-game qualification in this release. Existing runtime-update, backup and restoration safeguards remain in place. Intel XeSS / XeFG remain experimental.

Validation uses local builds, automated tests and fake game folders; no real-game validation of the final Hub binaries is claimed.
