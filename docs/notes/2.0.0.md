# RTX Encore Hub 2.0.0

**Guided setup:** on first installation in games without native integrations, choose frame generation and reconstruction independently, including None. Smooth Motion is no longer enabled automatically. Updates offer missing dependencies and preserve existing engine choices.

**Hub 2.0.0 is a major release.** Games that ship no DLSS at all now get DLSS, frame generation and Neural Rendering with RTX Encore 2.0.0, driven by a motion estimation engine RTX Encore wrote for them, and the Hub installs everything they use. RTX Encore and the Hub also have a new visual identity, with a new logo, and RTX Encore has its own Discord.

**RTX Encore now has a Discord.** Share your 2.0.0 results, compare settings, or get help with the mod and Hub. [Join the Discord](https://discord.gg/Zwmq4Xc2Br).

- **Games without DLSS:** RTX Encore 2.0.0 can run DLSS (DLAA, or upscaling to the screen's resolution) or Intel XeSS, Neural Rendering and frame generation on the image a game displays, in games that ship none of them. Frame generation is NVIDIA DLSS Frame Generation on DirectX 11, DirectX 12 and Vulkan, or Intel XeFG (X2 to X6 on DirectX 12, Vulkan and DirectX 11), per the engine chosen in the mod's menu, with a multiplier you can change while playing. In such a game, installing or updating mod 2.0.0 now brings everything these features use: `nvngx_dlss.dll` and `nvngx_dlssnr.dll` beside the mod, the Intel runtimes as before, and, where the game has neither frame generation nor Streamline of its own, the six DLSS Frame Generation files beside the executable (Streamline 2.14.16 from NVIDIA's SDK and `nvngx_dlssg.dll` 310.9.16, exact builds with a verified NVIDIA signature). The features themselves stay off: turn each one on in the mod's menu or in **All game settings**. Nothing is ever written over a file of the game, games that ship DLSS receive none of these files, and **Restore game** removes what was added.
- **Their settings in the Hub:** upscaling for games without DLSS, its output (**Game resolution (DLAA)** or **Screen resolution**) and engine (DLSS or XeSS), the motion estimation (**RTX Encore** by default, **Shader (vort)**, **Optical Flow (Quality)**, **Optical Flow (Fast)**), NR without game DLSS and frame generation for games without frame generation. Each one says what this game ships and what the Hub adds when it is turned on; choosing XeSS brings the Intel runtimes in the same change. The game page has a **Games without DLSS** section with the DLSS Frame Generation files, their state and a box to write the missing ones. From the command line, `setup --set` and `update <game>` bring the same files.
- **Smooth out X3 / X4, Automatic:** with mod 2.0.0, the choice is **Automatic** (the mod's default), **On** or **Off**. Automatic lets the mod measure how the generated frames reach the driver from X3 up and learn, per game, whether Streamline should pace them; the settings page shows what it learned, and **Measure again** clears it. Shared profiles carry only On or Off.
- **Mod menu language:** **Settings → Mod menu language** chooses the language of RTX Encore's in-game menu: **Same as Hub** (default) or one of the menu's eleven languages. An install or update of mod 2.0.0 writes it only in a game whose settings name no language yet, so a language picked in the in-game menu is kept. Changing the preference writes it in every game where the Hub installed the mod, each write undoable; games with an anti-cheat are left aside. The menu has no Arabic and shows English instead.
- **Twelve languages:** the Hub now also speaks German, Spanish, Dutch, Polish, Brazilian Portuguese, Vietnamese, Russian, Arabic (right to left) and Japanese, besides English, French and Simplified Chinese, tray menu included. Choose it in **Settings → Interface language**. Thanks to [@Matarto](https://github.com/Matarto) for the request ([#12](https://github.com/SilyNoMeta/rtx-encore-hub/issues/12)).
- **New logo:** a bevelled E in lime lacquered ceramic on a dark tile, with a light version. The Hub's icon, title bar, tray, installer and shortcuts show it.
- **Light theme:** **Settings → Theme** chooses dark, light or the one Windows uses, and **Settings → Icon** chooses the dark or light logo (by default the theme's) for the title bar, the taskbar and the notification area.
- **Mod 2.0.0:** installs and updates RTX Encore 2.0.0. The settings above are shown and written beside mod 2.0.0 or later only; earlier mods keep the settings they read.

The features for games without DLSS are experimental: the HUD is processed with the image, and turning frame generation for games without frame generation on or off needs a game restart. See the mod's [Games without DLSS](https://github.com/SilyNoMeta/rtx-encore/blob/main/docs/GAMES-WITHOUT-DLSS.md) page. The engine's automated tests, the interface checks, the mod contract, build, embedded versions, updater signature and distribution files were verified; no real game was tested with these files yet. Final binaries have no separate interactive retest.
