# RTX Encore Hub 1.4.6

- **Installation Intel dans les dossiers profonds :** corrige le refus d’installation, de réparation ou de réinstallation lorsque des contenus sans rapport sont trop imbriqués, comme les paquets Python fournis avec inZOI. Les fichiers Intel natifs des dossiers profonds sont désormais inclus dans le plan, avec les protections habituelles de sauvegarde et restauration.
- L’aperçu rapide reste limité. L’installation ignore toujours les liens et refuse une analyse incomplète si la limite d’entrées est atteinte ou si un dossier est illisible ; les contrôles d’intégrité restent obligatoires.

Ce correctif concerne le Hub et ne nécessite pas de nouvelle version du mod. Les tests automatisés locaux couvrent dossiers profonds, destinations natives, réparation et réinstallation. Les binaires finaux n’ont pas de validation distincte en jeu ; Intel XeSS / XeFG restent expérimentaux.
