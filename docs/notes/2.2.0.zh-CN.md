# RTX Encore Hub 2.2.0

**NIS 与抗锯齿设置：**安装 RTX Encore 2.2.0 后，无 DLSS 游戏可选择 NVIDIA Image Scaling。可在游戏设置中调整锐化，以及在缩放前后使用 FXAA 或 SMAA。仅当已安装的模组支持时，Hub 才显示这些选项。

**Overlay Studio：**预览并选择叠加层外观，包括新增经典样式；可单独选择 FPS、GPU、CPU、内存指标和可选图表。共享配置会保留这些选择。

**帧生成 Auto 覆盖：**当游戏请求 Auto 时，新设置会要求 NVIDIA 在游戏需要期间保持 DLSS-G 启用。搭配模组 2.2.0 时默认开启；若要保留 NVIDIA 的 Auto 行为，可将其关闭。Hub 在模组 2.2.0 或更新版本中显示该设置。

**RTX Encore 2.2.0：**Hub 可安装和更新[模组 2.2.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v2.2.0)，包括 RTX 20 实验性 XeFG Tensor Cores、RTX 30/40 XeSS Tensor Cores 更新，以及博德之门 3 和天国：拯救的修复。[模组完整说明](https://github.com/SilyNoMeta/rtx-encore/blob/main/CHANGELOG.zh-CN.md#220)。

本版本会检查 Hub 自动化测试、界面、模组设置契约、更新签名和分发文件。最终二进制文件尚未单独在游戏中复测。
