# RTX Encore Hub 1.4.6

- **Intel installation in deep game folders:** fixes installation, repair and reinstallation being refused because unrelated game content is nested too deeply, such as inZOI's bundled Python packages. Native Intel files in deep folders are now included in the installation plan and retain the normal backup and restore protections.
- The quick preview remains bounded. Installation still skips links and refuses an incomplete scan when the entry limit is reached or a folder cannot be read; integrity checks remain required.

This is a Hub fix; no new mod version is required. Local automated tests cover deep folders, native destinations, repair and reinstallation. The final binaries have not been separately validated in game; Intel XeSS / XeFG remain experimental.
