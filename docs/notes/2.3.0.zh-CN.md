# RTX Encore Hub 2.3.0

**配置 RTX Encore 2.3.0，比较 Neural Rendering 处理位置，并从稳定版安装 FSR 1。**

## 配套 2.3.0 设置

游戏运动矢量采用新默认值并支持回退；模组 2.3.0 可使用 NR 曝光和手动 XeFG 节奏。较旧模组保留其支持的选项和默认值。

## 引导安装 FSR 1

从稳定版 ZIP、本地文件夹和已安装的代理/ASI 识别 FSR 1。NIS 与 FSR 1 共享锐度和适用的 DirectX 11 SDR AA 控制，并保留兼容的 HDR/Vulkan 路径。

## NR 外观与比较

提供与模组版本对应的七种外观，不改变遍数、模型、分辨率或曝光。比较 Post-SR、Pre-SR 和最终画面导出，并在各卡片标明所选处理位置。

## 保留现有安装

保留明确设置。仅在新建配置时添加自动 NR 曝光；现有文件缺少该键时保留旧行为。社区配置支持最终画面和新的共享 XeFG 控制。

## 检测修复

从 Unity 游戏日志检测图形 API；文件夹仅残留 Streamline 文件且无原生帧生成时，仍可提供 DLSS-G 试用。
