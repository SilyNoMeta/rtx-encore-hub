# RTX Encore Hub 1.4.2

- **Where Winds Meet :** détecte le véritable exécutable du jeu dans ses dossiers Engine et propose d'installer le mod à côté.
- **Destinations d'installation :** une première installation exige un exécutable détecté. Lorsque la détection est incertaine, le Hub demande de confirmer l'exécutable avant de préparer l'installation.
- **Corriger une entrée existante :** choisir explicitement un exécutable dans Ajouter un jeu met à jour l'entrée existante sans doublon et invalide les anciens plans d'installation.

Une installation déjà placée dans le mauvais dossier n'est pas déplacée automatiquement par la mise à jour du Hub. Retirez l'installation erronée et réinstallez, ou utilisez le plan de changement de proxy existant pour choisir la bonne destination ; relisez les chemins proposés avant de l'appliquer. Installez [RTX Encore 1.4.4](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.4) pour le correctif NR correspondant dans Where Winds Meet.

Les tests automatisés locaux couvrent la détection, les plans et la confirmation sur des dossiers de jeux synthétiques. Les binaires finaux 1.4.2 n'ont pas de qualification distincte en jeu réel. Les protections de sauvegarde et de restauration restent disponibles.
