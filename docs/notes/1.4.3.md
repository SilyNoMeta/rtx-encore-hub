# RTX Encore Hub 1.4.3

- **Interrupted installation downloads:** automatically reconnects after a network or proxy interruption. Compatible downloads reuse already received data when integrity checks allow it; otherwise the file restarts. Retries are bounded and cancellable. Closing the Hub does not preserve partial downloads. Thanks to [@wer2357666](https://github.com/wer2357666) for the slow-download and proxy-switching report ([#4](https://github.com/SilyNoMeta/rtx-encore-hub/issues/4)). The separate in-game crash report remains unresolved.
- **Runtime cache storage:** on compatible NTFS volumes, downloaded NVIDIA, Intel and Streamline DLLs use transparent Windows compression. Existing cached DLLs are compressed in the background without removing cached versions; Storage usage reports their compressed size. Unsupported volumes and files that cannot be compressed keep their ordinary form. Thanks to [@SiTWulf](https://github.com/SiTWulf) for the storage feedback ([#5](https://github.com/SilyNoMeta/rtx-encore-hub/issues/5)).
- **Opening saved game data:** accepts valid UTF-8 JSON with or without a byte-order marker, and UTF-16 JSON with a supported byte-order marker, without rewriting the original files. Invalid or empty data stay protected and receive more useful diagnostics. Thanks to [@amernet91](https://github.com/amernet91) for the report and logs ([#6](https://github.com/SilyNoMeta/rtx-encore-hub/issues/6)); its exact cause is not yet confirmed.
- **Large game installations:** fixes native Intel runtime discovery stopping on very large or deeply nested game folders while retaining exclusions for linked directories.

Local automated tests cover interrupted and resumed downloads, corrupted data rejection, compression, encoded game state, backup restoration and directory scanning. Real VPN changes and the reporters' final cases have not been confirmed with these release binaries. This release changes the Hub; install the RTX Encore mod separately.
