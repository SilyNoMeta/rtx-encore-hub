# RTX Encore Hub 1.4.3

- **安装下载中断：**网络或代理切换导致中断后自动重连。兼容的下载会在完整性校验条件允许时尽可能复用已接收数据，否则重新下载。重试次数有限且可取消；关闭 Hub 不会保留未完成的下载。感谢 [@wer2357666](https://github.com/wer2357666) 提供下载缓慢及代理切换反馈（[#4](https://github.com/SilyNoMeta/rtx-encore-hub/issues/4)）。独立的游戏内崩溃报告仍未解决。
- **运行库缓存占用：**在兼容的 NTFS 卷上，下载的 NVIDIA、Intel 和 Streamline DLL 使用 Windows 透明压缩。现有缓存 DLL 会在后台压缩，不删除缓存版本；存储用量显示压缩后的大小。不支持的卷或文件保持原有形式。感谢 [@SiTWulf](https://github.com/SiTWulf) 的存储反馈（[#5](https://github.com/SilyNoMeta/rtx-encore-hub/issues/5)）。
- **读取已保存的游戏数据：**支持有效的 UTF-8 JSON（可带字节顺序标记）及带受支持字节顺序标记的 UTF-16 JSON，不重写原文件。无效或空数据继续受到保护，并提供更有用的诊断。感谢 [@amernet91](https://github.com/amernet91) 提供报告和日志（[#6](https://github.com/SilyNoMeta/rtx-encore-hub/issues/6)）；其具体原因尚未确认。
- **大型游戏安装：**修复 Intel 原生运行库扫描在文件特别多或目录很深时停止的问题，同时继续排除链接目录。

本地自动化测试覆盖下载中断及恢复、拒绝损坏数据、压缩、编码后的游戏数据、备份恢复和目录扫描。尚未使用最终文件确认真实 VPN 切换或报告者的最终案例。本次更新针对 Hub；RTX Encore 模组需单独安装。
