# RTX Encore Hub 2.1.0

**Cadence du jeu régulière pour XeFG :** le nouveau réglage de RTX Encore 2.1.0 est dans **Tous les réglages de ce jeu**, activé par défaut. À partir de X3, il lance les images du jeu à intervalle régulier, juste sous la cadence que le jeu peut tenir, pour que les mouvements de caméra restent réguliers entre les images générées par XeFG ; il coûte quelques FPS et s'applique pendant que le jeu tourne. Le Hub l'affiche et l'écrit à côté d'un mod 2.1.0 ou plus récent, et les profils partagés le transportent.

**Choisir ce qui est installé :** chaque installation et mise à jour d'un jeu ouvre maintenant **Choisir les composants** avant l'aperçu des fichiers. Choisissez le mod, chaque DLL NVIDIA séparément (Super Resolution, Ray Reconstruction, Frame Generation, Neural Rendering), un jeu de plugins Streamline, Intel XeSS / XeFG / XeLL et les fichiers DLSS Frame Generation facultatifs ; chaque DLL dit à quoi elle sert. Les fichiers décochés restent exactement tels quels : un jeu qui refuse les plugins Streamline plus récents garde les siens. **Choisir les composants** reste sur la fiche d'un jeu installé, pour ajouter plus tard un composant ignoré sans réinstaller le mod, et les mises à jour groupées suivent le choix de chaque jeu. Merci à [@o5-null](https://github.com/o5-null), dont le signalement sur Call of Duty a montré pourquoi ([rtx-encore#110](https://github.com/SilyNoMeta/rtx-encore/issues/110)).

- **Mod 2.1.0 :** installe et met à jour [RTX Encore 2.1.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v2.1.0) : XeFG fluide à partir de X3, la profondeur et le mouvement du jeu pour la génération d'images ajoutée, XeFG sur les Tensor Cores en DirectX 11 et Vulkan, et des corrections pour Baldur's Gate 3, Final Fantasy VII Rebirth, Forza Horizon 6, Kingdom Come: Deliverance, Islands of Insight et Assassin's Creed Black Flag Resynced.

Les tests automatisés du Hub, les vérifications de l'interface, le contrat du mod, le build, la version embarquée, la signature de mise à jour et les fichiers de distribution ont été vérifiés. Les binaires finaux n'ont pas eu de nouveau test interactif séparé.
