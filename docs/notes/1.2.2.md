# RTX Encore Hub 1.2.2

- **Hub logs you can export even when game pages fail.** Use **Settings → Hub diagnostics → Export Hub logs**, or the export button on a failed game page. The archive includes recent Hub activity and errors; review it before attaching it to an issue. Thanks to [@amernet91](https://github.com/amernet91) for the report that prompted this improvement ([#6](https://github.com/SilyNoMeta/rtx-encore-hub/issues/6)). This adds diagnostics; the reported game-list failure is still under investigation.
- **Smaller original-file backups.** Game originals are now kept in verified ZIP archives. Existing uncompressed backups remain restorable and are converted on the next successful installation or update. Keep this Hub version or a newer one to restore compressed backups. Runtime storage and operation history are unchanged. Thanks to [@SiTWulf](https://github.com/SiTWulf) for the storage suggestion ([#5](https://github.com/SilyNoMeta/rtx-encore-hub/issues/5)).
- **Remembered selections and accessible actions.** The game page remembers the last preset, multiplier and option selections on this device. Back and Apply stay available while scrolling through the game page and all settings. Selections are applied only after confirmation. Thanks to [@wer2357666](https://github.com/wer2357666) for these suggestions ([#4](https://github.com/SilyNoMeta/rtx-encore-hub/issues/4)); this does not claim to fix the game crashes reported in that issue.

The Hub and RTX Encore mod have separate version numbers. This release does not change the mod. Intel XeSS and XeFG remain experimental.
