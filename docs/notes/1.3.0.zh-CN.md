# RTX Encore Hub 1.3.0

- **RTX Encore 1.3.0 的中央优先 NR 设置。** 游戏设置现可使用模组的实验性中央优先 Neural Rendering，默认关闭：开启中央优先 NR，然后选择预设（light、balanced、strong），或选择 custom 并设置四个数值（全强度中央区域的宽度和高度、过渡长度、边缘保留的细节）。边缘附近的 NR 效果更柔和。模组在 RTX 3070 Ti Laptop 上的 Cyberpunk 2077 中测得 Strong 平均 FPS 提升 27%。这些设置可随社区配置分享。
- **RTX 20 的 Smooth Motion V1 或 V2。** 检测到 RTX 20 显卡且使用 RTX Encore 1.3.0 时，可选择 V1（测试版 1，默认）或 V2（测试版 2），然后重启游戏。其他显卡不显示此选项，且该选项本身不会开启 Smooth Motion。仍需 621.01 驱动和 DirectX 12。
- **移除 OpenNR 和 Cyber Engine Tweaks 面板。** RTX Encore 1.3.0 已将其移除，Hub 不再显示相关设置；NVIDIA Neural Rendering 仍可使用。旧面板留下的设置在模组导入前仍可读取，新设置写入模组旁。
- **设置中的存储空间。** 可查看应用程序、共享和本地备份、已下载运行库、RTX Encore 压缩包、游戏封面、日志及其他 Hub 数据所占空间，以及仍保存在游戏目录中的旧备份。部分扫描会明确提示，此时显示的总量为最小值。
- **备份维护不再重复同一警告。** 当游戏目录中有并非 Hub 创建的备份文件夹，或同一游戏曾以其他标识记录时，Hub 现在会完成自身数据的迁移，并保持该文件夹不变。剩余警告会显示游戏名称，未处理的文件会被保留。

中央优先 NR 和 RTX 20 的 V1/V2 选择需要 RTX Encore 1.3.0 或更高版本；旧模组保留当前设置。请保留完整 Hub 数据：还原迁移后的状态仍需要 Hub 1.2.4 或更高版本。Hub 检查文件和设置，不认证画质或游戏内性能。测试使用虚拟游戏，不代表真实游戏验证。
