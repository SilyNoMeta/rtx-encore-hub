## 2.5.0

- **Choose the in-game menu key in the Hub.** Open **Settings → Install defaults → In-game menu key** and choose a key. Use **Apply to games** to update games where the Hub already installed Encore. The new key takes effect on the next game launch. This also works when an overlay conflict prevents opening the menu in-game.
- **Record shortcuts from the keyboard.** In a game's settings, press the desired key combination to bind it. You can remove individual bindings or restore the default. The mod supports up to three bindings per action.
- Matches RTX Encore 2.5.0.
