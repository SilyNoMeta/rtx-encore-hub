# RTX Encore Hub 1.5.2

- **Faster update handover:** requesting a Hub update cancels cancellable startup background work, so scans and downloads no longer unnecessarily delay the update. Active game operations still finish before installation.
- **Mod 1.5.1 compatibility:** hides the retired RTX 20 Smooth Motion V1/V2 selector, stops writing or sharing it for the new mod, and explains why an old shared value cannot be imported. Mods 1.3.0 through 1.5.0 retain their variant selection.
- **Support:** thanks to [@Scarhead666](https://github.com/Scarhead666) and the public sponsors supporting RTX Encore.

The full automated suite was not rerun for this maintenance release. The release build, focused compatibility checks, embedded versions, updater signature and distribution files were checked. Final binaries have no separate interactive retest.
