# RTX Encore Hub 1.2.0-beta.1

**XeSS / XeFG：高度实验性。** 这部分集成的开发过程非常艰难，也相当折腾 :) 请预期可能出现错误、崩溃、画面伪影，以及不同游戏和图形 API 之间的行为差异。欢迎报告问题：在 RTX Encore Hub 中打开游戏的 **健康检查** 页面，选择 **生成诊断包**，检查并移除个人信息后，将诊断压缩包附加到 [RTX Encore issue](https://github.com/SilyNoMeta/rtx-encore/issues/new/choose)。请注明选择的引擎、图形 API 和请求的倍率。Hub 不会自动上传该压缩包。

这是预发布版本。若要在 Hub 中接收测试版更新，请在 **更新** 页面选择 **候选版** 通道；稳定版通道仍使用稳定发布版本。

## Intel 引擎及依赖

搭配 RTX Encore 1.2.0-beta.1，可在模组支持的场景中选择 XeSS 重建或 XeFG 帧生成。Hub 会随模组安装并验证 Intel 文件及许可证，在同一操作中备份和还原它们。文件已安装不能证明引擎已激活。

## 逐轮调整 Neural Rendering

四轮处理中的每一轮都可以调整强度、局部色调、局部结构、皮肤结构和角色遮罩，也可以继承全局设置。强度设为零仍会运行该轮处理，不会消除其计算开销。

使用 RTX Encore 1.2.0-beta.1 时，NR 还可在提供兼容线性深度输入的 Direct3D 12 游戏中于 Ray Reconstruction 之后运行。Direct3D 11 和 Vulkan 仍不支持此情况。007 First Light 路径追踪的本地测试确认 NR 可以运行；尚未测量画质和开销。偶发启动崩溃仍未解决。

## HDR 输入与曝光

共用设置 `srHdr` 和 `srAutoExposure` 跟随所选重建引擎，默认跟随游戏，需要重启生效。HDR 输入不会开启显示器 HDR，也不会将 SDR 转换为 HDR。

## 找到正确的游戏

全局搜索可直接打开游戏页面。当可执行文件不确定时，游戏页面会提供候选项并记住您的选择，也可以恢复自动选择。

## 更有用的诊断

健康页面报告帧生成提供程序，以及精确配置准入、未经认证的启发式准入或拒绝。诊断压缩包包含模组文本日志、设置和游戏目录文件列表。分享前请检查内容；Hub 不会自动上传。

## 兼容性与限制

新的 Intel、共用输入、逐轮 NR 和提供程序策略设置需要已识别的模组 1.2.0-beta.1 或更高版本。旧模组保留其支持的控制项。XeFG 路径仍属实验性，取决于模组、图形 API、游戏和运行库。更高倍率有使用条件；请求的倍率不能证明实际显示的帧数。

提供程序策略仅适用于本地游戏：`exact` 仅接受已审查的 NVIDIA 提供程序；模组默认的 `heuristic` 还允许与其他签名提供程序进行受限兼容。启发式准入仍未经认证，并会在健康页面标明。修改后需重启；此设置不参与社区配置分享。

使用 XeFG 时，修改 FPS 上限需要重启游戏。较高 XeFG 倍率的可变帧间隔属于实验性功能。FPS 上限不能证明源帧节奏。

Hub 的改动已在本地模拟游戏目录中检查，包括安装计划与还原。这些检查不能认证引擎在您的游戏中可用，也不能测量显示延迟。现有截图为带日期的示例，并未展示测试版的全部新功能。
