# RTX Encore Hub 1.3.1

- **更安全地更新旧游戏的 Streamline。** Hub 保留兼容的整套 Streamline 组件，避免提供不兼容的新旧文件组合。此修复跟进 [@dm1z0r](https://github.com/dm1z0r) 的 WRC Generations 报告（[RTX Encore #75](https://github.com/SilyNoMeta/rtx-encore/issues/75)）。
- **NVIDIA 运行库选项遵循游戏的集成方式。** 对于旧版或无法识别的 Streamline 集成，Hub 保留现有 NVIDIA 文件，不提供兼容性尚未确认的更新。全局和可选设置同样遵循此规则。游戏页面会说明更新不可用的原因。

模组的 WRC Generations 兼容性修复请使用 RTX Encore 1.3.1。此 Hub 版本不代表已为该游戏验证所有新版 NVIDIA 运行库，也不会自动修复在 Hub 之外替换的文件。现有备份与还原保护继续生效。

验证使用自动化测试和模拟游戏文件夹；未声称最终 Hub 二进制文件已在真实游戏中验证。Intel XeSS / XeFG 仍属实验性。
