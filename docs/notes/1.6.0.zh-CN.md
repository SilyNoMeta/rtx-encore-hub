# RTX Encore Hub 1.6.0

- **Ctrl+F 跳到游戏搜索：**在任何页面按 `Ctrl+F` 都会选中标题栏的搜索框，不再打开窗口自带的空白查找栏。搜索框提示中写明了此快捷键；`Ctrl+K` 仍打开命令面板。
- **还原游戏可同时清理：**“还原游戏”确认框中默认不勾选的**同时删除我的设置和日志**，还会删除模组旁和可执行文件旁的 `rtx-encore.jsonc` 与 `rtx-encore-logs` 文件夹；私有目录 `rtx-encore-runtimes` 仅在只含 Hub 添加的文件时删除。其他内容保持原样并被报告；还原本身照常完成。CLI 中也可使用 `restore <游戏> --clean`。感谢 [@SiTWulf](https://github.com/SiTWulf) 提交报告（[#8](https://github.com/SilyNoMeta/rtx-encore-hub/issues/8)）。
- **模组 1.6.0：**安装并更新 RTX Encore 1.6.0。其设置与模组 1.5.3 相同，Hub 的设置页面、迁移和共享配置保持不变。

未重新运行完整自动化测试套件。已验证针对性检查、mod 契约、编译、嵌入版本、更新签名及发布文件。最终文件未单独进行交互复测。
