# RTX Encore Hub 1.2.2

- **游戏页面无法打开时也能导出 Hub 日志。** 使用**设置 → Hub 诊断 → 导出 Hub 日志**，或出错游戏页面上的导出按钮。压缩包包含 Hub 最近的活动和错误；附到问题反馈前请先检查内容。感谢 [@amernet91](https://github.com/amernet91) 的反馈促成这项改进（[#6](https://github.com/SilyNoMeta/rtx-encore-hub/issues/6)）。此功能用于诊断，其游戏列表读取问题仍在调查中。
- **更小的原始文件备份。** 游戏原始文件现以经过校验的 ZIP 压缩包保存。旧的未压缩备份仍可还原，并在下次成功安装或更新时转换。请保留本版或更新版 Hub，以还原压缩备份。运行库存储和操作历史保持不变。感谢 [@SiTWulf](https://github.com/SiTWulf) 的建议（[#5](https://github.com/SilyNoMeta/rtx-encore-hub/issues/5)）。
- **记住选择，操作按钮随时可用。** 游戏页面会在本机记住上次选择的预设、倍率和选项。滚动游戏页面或全部设置时，返回和应用按钮始终可用。选择只有在确认后才会应用。感谢 [@wer2357666](https://github.com/wer2357666) 的建议（[#4](https://github.com/SilyNoMeta/rtx-encore-hub/issues/4)）；这并不表示已修复该问题中报告的游戏崩溃。

Hub 与 RTX Encore 模组采用独立版本号。本次发布不修改模组。Intel XeSS 和 XeFG 仍为实验性功能。
