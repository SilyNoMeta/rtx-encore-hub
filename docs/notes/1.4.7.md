# RTX Encore Hub 1.4.7

- **Cleaner uninstall:** removes the empty private Intel runtime folders recorded by the installation after restoring the game. Restored originals, unrelated files, game folders, personal settings and logs are preserved. Thanks to [@SiTWulf](https://github.com/SiTWulf) for the report ([#8](https://github.com/SilyNoMeta/rtx-encore-hub/issues/8)).
- The user guide now explains why settings and logs remain after uninstalling the mod.

Local automated tests cover empty-folder cleanup and preservation of restored files and user data. No separate final-binary in-game validation is claimed. This Hub fix does not require a new mod version; [RTX Encore 1.4.7](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.7) separately fixes The Witcher 3 NR shadow flickering.
