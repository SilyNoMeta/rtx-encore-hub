# RTX Encore Hub 1.4.5

- **帧生成引擎：**增加 NVIDIA DLSS-FG 选项，供 Mirage 等兼容的原生 Intel FG 游戏使用。游戏选项保留原生引擎；XeFG 保留现有 Intel 替换路径。FSR 保持原生。更换 FG 引擎后请重启游戏。
- **Reflex：**增加游戏 / On / On+Boost 以及渲染帧延迟报告。不会降低游戏模式，在动态模式或 XeLL 管理延迟时暂停；不保证降低延迟。
- **社区配置模板：**支持新 FG/Reflex 选项及延迟显示的导入导出，在线校验器同步更新。保留现有配置及其他设置。

配合 [RTX Encore 1.4.6](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.6) 和兼容运行库使用。本地自动化测试覆盖设置、配置往返和校验；最终 Hub 文件无单独游戏验证。
