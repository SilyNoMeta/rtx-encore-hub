# RTX Encore Hub 1.3.1

- **Safer Streamline updates for older games.** The Hub keeps compatible Streamline components together instead of offering an incompatible mixture of old and new files. This addresses the WRC Generations report from [@dm1z0r](https://github.com/dm1z0r) ([RTX Encore #75](https://github.com/SilyNoMeta/rtx-encore/issues/75)).
- **NVIDIA runtime choices respect the game's integration.** For older or unrecognized Streamline integrations, the Hub preserves existing NVIDIA files and withholds updates whose compatibility has not been established. This also applies to global and optional choices. The game page explains why an update is unavailable.

Use RTX Encore 1.3.1 for the mod's WRC Generations compatibility fixes. This Hub release does not certify every recent NVIDIA runtime for that game, and it does not automatically repair files replaced outside the Hub. Existing backup and restoration safeguards remain in place.

Validation uses automated tests and fake game folders; no real-game validation of the final Hub binaries is claimed. Intel XeSS / XeFG remain experimental.
