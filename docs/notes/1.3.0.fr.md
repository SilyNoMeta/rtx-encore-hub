# RTX Encore Hub 1.3.0

- **Réglages du NR fovéal pour RTX Encore 1.3.0.** Les réglages d’un jeu proposent le Neural Rendering fovéal expérimental du mod, désactivé par défaut : activez le NR fovéal, puis choisissez un préréglage (light, balanced, strong) ou custom avec ses quatre valeurs (largeur et hauteur du centre à pleine force, longueur de la transition, détail conservé sur les bords). L’effet NR est plus doux près des bords. Le mod a mesuré +27 % de FPS moyen avec Strong dans Cyberpunk 2077 sur une RTX 3070 Ti Laptop. Ces réglages peuvent circuler dans les profils de la communauté.
- **Smooth Motion V1 ou V2 sur RTX 20.** Avec une carte RTX 20 détectée et RTX Encore 1.3.0, choisissez V1 (test 1, par défaut) ou V2 (test 2), puis relancez le jeu. Le choix est masqué sur les autres cartes et n’active jamais Smooth Motion à lui seul. Le pilote 621.01 et DirectX 12 restent nécessaires.
- **Fin d’OpenNR et du panneau Cyber Engine Tweaks.** RTX Encore 1.3.0 les a retirés : le Hub n’affiche plus leurs réglages ; le Neural Rendering NVIDIA reste disponible. Les réglages laissés par l’ancien panneau restent lisibles jusqu’à leur import par le mod, et les nouveaux réglages sont écrits à côté du mod.
- **Espace utilisé dans les Paramètres.** Voyez la place prise par l’application, les sauvegardes partagées et locales, les runtimes téléchargés, les archives RTX Encore, les jaquettes, les journaux et les autres données du Hub, ainsi que les anciennes sauvegardes encore présentes dans les dossiers des jeux. Une analyse partielle est signalée, et son total est alors un minimum.
- **La maintenance des sauvegardes ne répète plus le même avertissement.** Quand le dossier d’un jeu contient un dossier de sauvegarde que le Hub n’a pas créé, ou que le même jeu a été enregistré auparavant sous une autre identité, le Hub termine le déplacement de ses propres données et laisse ce dossier intact. Les avertissements restants nomment le jeu, et les fichiers non traités sont conservés.

Le NR fovéal et le choix V1/V2 sur RTX 20 nécessitent RTX Encore 1.3.0 ou ultérieur ; les anciens mods gardent leurs réglages actuels. Gardez les données complètes du Hub : les états migrés nécessitent toujours Hub 1.2.4 ou ultérieur pour être restaurés. Le Hub vérifie les fichiers et les réglages ; il ne certifie ni la qualité d’image ni les performances en jeu. Tests sur faux jeux ; aucune validation en jeu réel n’est revendiquée.
