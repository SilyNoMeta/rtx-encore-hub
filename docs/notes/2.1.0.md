# RTX Encore Hub 2.1.0

**Steady game pacing for XeFG:** RTX Encore 2.1.0's new setting is in **All game settings**, on by default. From X3, it starts the game's frames on a regular schedule just below the rate the game can sustain, so camera motion stays even across XeFG's generated images; it costs a few FPS and applies while the game runs. The Hub shows and writes it beside mod 2.1.0 or later, and shared profiles carry it.

**Choose what gets installed:** every installation and game update now opens **Choose components** before the file preview. Pick the mod, each NVIDIA DLL separately (Super Resolution, Ray Reconstruction, Frame Generation, Neural Rendering), a Streamline plugin set, Intel XeSS / XeFG / XeLL and the optional DLSS Frame Generation files; each DLL says what it is for. Unchecked files are left exactly as they are, so a game that refuses newer Streamline plugins keeps its own. **Choose components** stays on an installed game's page, to add a component you skipped later without reinstalling the mod, and bulk updates follow each game's choice. Thanks to [@o5-null](https://github.com/o5-null) whose Call of Duty report showed why ([rtx-encore#110](https://github.com/SilyNoMeta/rtx-encore/issues/110)).

- **Mod 2.1.0:** installs and updates [RTX Encore 2.1.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v2.1.0): smooth XeFG at X3 and above, the game's own depth and motion for added frame generation, XeFG on Tensor Cores in DirectX 11 and Vulkan, and fixes for Baldur's Gate 3, Final Fantasy VII Rebirth, Forza Horizon 6, Kingdom Come: Deliverance, Islands of Insight and Assassin's Creed Black Flag Resynced.

The Hub's automated tests, the interface checks, the mod contract, build, embedded version, updater signature and distribution files were verified. The final binaries have no separate interactive retest.
