# RTX Encore Hub 1.4.0

- **RTX Encore 1.4.0 设置：** 选择实验性 Pre-SR 或默认 Post-SR、使用 Pre-SR 配方，并为每轮 NR 独立选择模型配置。这些设置需要模组 1.4.0；保存选择不代表游戏已实际采用。
- **NR 比较报告：** 在游戏内打开图像与性能实验室采集测量和截图，导出后将 JSON 报告导入 Hub。Hub 显示 NR/SR 耗时及各自独立的内存计数；不可用的测量保持不可用。
- **经确认的比较：** 相对结果要求观测到的游戏条件一致，且 SR/FG 视口关联已确认。旧报告和未确认报告仍可读取，但不会判定为可比较。当前缺少该关联的原生路径仅提供各组观测，不报告相对提升。连续截图不能证明时间稳定性，全局内存变化也不能证明 Pre-SR 带来的节省。

请单独安装 RTX Encore 1.4.0，以获得原生菜单语言、关于选项卡、DLSS-G 修复和 NR 实验室。Post-SR 仍为默认模式。本版本的 Pre-SR、新的多轮路径及比较工具尚未经过 GPU 或游戏内验证。现有运行库更新、备份和恢复保护继续保留。Intel XeSS / XeFG 仍为实验性功能。

验证使用本地构建、自动化测试和模拟游戏目录；不宣称最终 Hub 二进制文件已经过真实游戏验证。
