# RTX Encore Hub 2.2.0

**NIS and anti-aliasing controls:** install RTX Encore 2.2.0 and choose NVIDIA Image Scaling for games without DLSS. Adjust sharpness and optional FXAA or SMAA before or after scaling from the game's settings. The Hub offers these controls when the installed mod supports them.

**Overlay Studio:** preview and choose the overlay's appearance, including the new classic style, and select individual FPS, GPU, CPU and memory metrics plus an optional graph. The chosen settings travel with shared profiles.

**Frame generation Auto override:** when a game asks for Auto frame generation, the new setting asks NVIDIA to keep DLSS-G On while the game wants it. It is on by default with mod 2.2.0; turn it off to keep NVIDIA's Auto behavior. The Hub shows it with mod 2.2.0 or later.

**RTX Encore 2.2.0:** the Hub installs and updates the [mod 2.2.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v2.2.0), including experimental XeFG Tensor Cores on RTX 20, updated XeSS Tensor Cores paths for RTX 30/40, and the Baldur's Gate 3 and Kingdom Come: Deliverance fixes. [Full mod notes](https://github.com/SilyNoMeta/rtx-encore/blob/main/CHANGELOG.md#220).

The Hub's automated tests, interface checks, mod settings contract, signed updater and distribution files are checked for this release. The final binaries have no separate interactive game retest.
