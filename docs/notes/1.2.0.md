# RTX Encore Hub 1.2.0

[English](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0.md) · [Français](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0.fr.md) · [简体中文](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0.zh-CN.md)

Includes everything from 1.2.0-beta.1. **XeSS / XeFG remain VERY EXPERIMENTAL.** Expect bugs, crashes, visual artifacts and differences between games and graphics APIs. Please report problems: in RTX Encore Hub, open the game’s **Health** page, choose **Prepare a diagnostic**, review the archive for personal information, then attach it to an [RTX Encore issue](https://github.com/SilyNoMeta/rtx-encore/issues/new/choose). The Hub does not upload the archive for you.

## Your library

- **Favorites**, a separate favorites row and compact actions on each game card; launch a game from its card.
- **Optional tray mode**: closing the window can leave the Hub in the notification area, and reopening it resumes the library where it was.
- The title-bar search filters the library directly.
- The Hub keeps the game's original files locally and caches the mod archives it offers, so restoring and reinstalling need fewer downloads.

## With RTX Encore 1.2.0

- **Smooth Motion on NVIDIA driver 621.01** (RTX 30), with RTX Encore 1.2.0 or later. An older mod in a game is reported as needing 1.2.0.
- **Force Smooth Motion is gone**: with Smooth Motion on in a Vulkan game, the mod 1.2.0 always lifts the driver's per-game exclusion. Unexpected results remain possible in such games.
- **DLSS presets and the reconstruction engine** now apply while the game runs with RTX Encore 1.2.0, so the Hub no longer asks for a restart for them. In a Vulkan game, choose XeSS before starting it.

## Also in 1.2

Intel XeSS and XeFG with their dependencies, Neural Rendering pass by pass, common HDR input and exposure controls, a global search that opens games, executable candidates, and fuller diagnostics arrived in 1.2.0-beta.1: see [its notes](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0-beta.1.md).

## Compatibility and limits

Intel, common-input, per-pass NR and provider-policy settings require an identified mod 1.2.0-beta.1 or later; Smooth Motion on driver 621.01 requires 1.2.0. Older mods keep their supported controls. XeFG routes are experimental and limited by the mod, graphics API, game and runtime; a requested multiplier is not proof of displayed frames.

The Hub changes were checked with its automated tests and stand-in game folders. Those checks do not qualify an engine in your game or measure display latency.
