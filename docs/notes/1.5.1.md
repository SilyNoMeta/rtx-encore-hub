# RTX Encore Hub 1.5.1

- **Lower idle GPU activity:** removes continuously animated visual effects that could keep the GPU busy while Hub was open. Thanks to [@SiTWulf](https://github.com/SiTWulf) for the report ([#9](https://github.com/SilyNoMeta/rtx-encore-hub/issues/9)).
- **Community profiles:** improves read retries and loading/error feedback, avoiding a misleading unavailable state during a temporary loading failure.
- **Installation actions:** makes installation easier to find in the library and game details. The floating action appears after the contextual button scrolls out of view.
- **Intel verification:** checks installed dependencies with the same complete scan as installation, including deeply nested native files.

XeSS and XeFG Tensor Cores from 1.5.0 remain available with their existing requirements. The maintainer reports the local build works. The automated test suite was not rerun for this release; the release build, embedded version, updater signature and distribution files were checked.
