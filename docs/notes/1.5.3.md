# RTX Encore Hub 1.5.3

- **Update favorites only:** the bulk-update dialog can limit updates to starred games, while the library keeps its overall update status. Also available as `update --favorites` in the CLI. Thanks to [@mennogreg](https://github.com/mennogreg) for the request ([#11](https://github.com/SilyNoMeta/rtx-encore-hub/issues/11)).
- **Tensor controls on RTX 30/40/50:** offers both independent XeSS and XeFG Tensor Cores switches with the matching mod version. RTX 30 and RTX 50 require mod 1.5.3; existing RTX 40 controls retain their version range. NVIDIA 621.01 and the experimental 621.12 hotfix are admitted by mod 1.5.3. Only the earlier RTX 4090 / 621.01 setup has in-game qualification.
- **V-Sync Game / Off / On:** exposes the mod 1.5.2 three-way control and carries over older saved V-Sync-off values. Use compatible DirectX games; Vulkan and XeSS-FG are excluded, and forcing On can add latency.
- **RR preset F:** adds the new Ray Reconstruction choice where compatible runtimes allow it. Thanks to [@dm1z0r](https://github.com/dm1z0r) for the request ([#95](https://github.com/SilyNoMeta/rtx-encore/issues/95)).
- **Contract and community profiles:** synchronizes settings, migration, hardware/version conditions and shared-profile validation with mod 1.5.3.

The full automated suite was not rerun. Focused checks, the mod contract, build, embedded versions, updater signature and distribution files were verified. Final binaries have no separate interactive retest.
