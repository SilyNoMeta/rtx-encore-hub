# RTX Encore Hub 1.4.4

- **Native Smooth Motion settings:** enables the existing controls on RTX 40/50 when the installed mod is RTX Encore 1.4.5 or newer and the driver is supported. Select the actual graphics API and restart the game. The mod's simple 2x FPS counter is an estimate, not a measurement of interpolated frames.
- **Graphics API detection:** recognizes common dynamically loaded DirectX APIs before treating bundled middleware loaders as evidence, including Men of War II. This remains a probable static detection; verify the game's actual API. Initial recommendations consider available features and preserve explicit choices and existing settings.
- **Shared backups and restoration:** improves independent migration of verifiable backup records, preserves recovery information when an original copy is missing, and avoids recreating absent game folders. Existing backup digests and restoration checks remain required.
- **Downloads and cache:** checks completion more strictly, restarts invalid resumed downloads, reuses matching Intel runtime versions and improves coordination between runtime readers and background compression.
- **Installation plans and diagnostics:** requires an uncertain executable choice to be confirmed before operations that write game files, reports incomplete Intel scans and refuses installation plans that cannot establish a complete safe result. Exported logs redact additional absolute paths, including legacy exports; review diagnostics before sharing.

Local automated tests cover these changes. The maintainer observed native Smooth Motion preparation on RTX 4090/621.01 with a test build, not an interpolated-frame count. The final Hub binaries have no separate real-game validation; RTX 50 hardware and native Vulkan remain unqualified. An existing incomplete backup cannot be repaired without an available verified original. [RTX Encore 1.4.5](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.5) is a separate mod release.
