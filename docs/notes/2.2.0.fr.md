# RTX Encore Hub 2.2.0

**Réglages NIS et anticrénelage :** installez RTX Encore 2.2.0 et choisissez NVIDIA Image Scaling dans les jeux sans DLSS. Réglez la netteté et, si vous le souhaitez, FXAA ou SMAA avant ou après la mise à l'échelle dans les paramètres du jeu. Le Hub affiche ces commandes lorsque le mod installé les prend en charge.

**Overlay Studio :** prévisualisez et choisissez l'apparence de l'overlay, dont le nouveau style classique, les métriques FPS, GPU, CPU et mémoire affichées séparément, ainsi qu'un graphique optionnel. Les profils partagés transportent ces choix.

**Override du mode Auto pour la génération d'images :** lorsqu'un jeu demande Auto, ce nouveau réglage demande à NVIDIA de garder DLSS-G actif tant que le jeu le veut. Il est activé par défaut avec le mod 2.2.0 ; désactivez-le pour conserver le comportement Auto de NVIDIA. Le Hub l'affiche avec le mod 2.2.0 ou plus récent.

**RTX Encore 2.2.0 :** le Hub installe et met à jour le [mod 2.2.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v2.2.0), dont XeFG expérimental sur les Tensor Cores des RTX 20, les nouveaux chemins XeSS Tensor Cores pour RTX 30/40 et les corrections pour Baldur's Gate 3 et Kingdom Come: Deliverance. [Toutes les notes du mod](https://github.com/SilyNoMeta/rtx-encore/blob/main/CHANGELOG.fr.md#220).

Les tests automatisés du Hub, les contrôles de l'interface, le contrat des réglages du mod, la signature de mise à jour et les fichiers de distribution sont vérifiés pour cette version. Les binaires finaux n'ont pas été retestés séparément en jeu.
