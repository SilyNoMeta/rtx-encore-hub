# RTX Encore Hub 1.4.2

- **Where Winds Meet:** detects the actual game executable inside the game's Engine folders and proposes installing the mod beside it.
- **Installation destinations:** a first installation requires a detected executable. When detection is uncertain, the Hub asks you to confirm the executable before preparing the installation.
- **Correct an existing library entry:** explicitly selecting an executable through Add game updates the existing entry without duplicating it and invalidates outdated installation plans.

An installation already placed in the wrong folder is not automatically moved by updating the Hub. Remove the misplaced installation and install again, or use the existing proxy-change plan to choose the correct destination; review the proposed paths before applying it. Install [RTX Encore 1.4.4](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.4) for the matching NR compatibility fix in Where Winds Meet.

Local automated tests cover discovery, installation plans and confirmation using synthetic game folders. The final 1.4.2 binaries have no separate real-game qualification. Existing backup and restoration protections remain available.
