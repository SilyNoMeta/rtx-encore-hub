# RTX Encore Hub 1.6.0

- **Ctrl+F goes to the game search:** from any page, `Ctrl+F` selects the search field in the title bar instead of opening the window's empty find bar. The field's hint names the shortcut; `Ctrl+K` still opens the command palette.
- **Restore game can also clean up:** the **Also delete my settings and logs** box, unticked by default in the Restore game confirmation, also deletes `rtx-encore.jsonc` and the `rtx-encore-logs` folder, beside the mod and beside the executable, and the private `rtx-encore-runtimes` folder when it holds only files the Hub added. Anything else is left as it is and reported; the restore itself stays done. Also available as `restore <game> --clean` in the CLI. Thanks to [@SiTWulf](https://github.com/SiTWulf) for the report ([#8](https://github.com/SilyNoMeta/rtx-encore-hub/issues/8)).
- **Mod 1.6.0:** installs and updates RTX Encore 1.6.0. Its settings are those of mod 1.5.3, so the Hub's settings pages, migration and shared profiles carry over unchanged.

The full automated suite was not rerun. Focused checks, the mod contract, build, embedded versions, updater signature and distribution files were verified. Final binaries have no separate interactive retest.
