# RTX Encore Hub 1.4.4

- **原生 Smooth Motion 设置：**在 RTX 40/50、受支持驱动及 RTX Encore 1.4.5 或更高版本上提供现有控制。请选择实际图形 API 并重启游戏。模组的简单 2x FPS 计数是估算，不是插值帧测量。
- **图形 API 检测：**优先识别常见动态加载的 DirectX API，而非游戏附带的中间件加载器，包括战争之人 II。静态检测仍只是推测，请核实实际 API。初始建议考虑可用功能，并保留明确选择及既有设置。
- **共享备份与恢复：**改进可验证记录的独立迁移，在缺失原件时保留恢复信息，并避免重建已不存在的游戏目录。仍要求备份摘要及恢复校验。
- **下载与缓存：**更严格地检查下载完成，重新下载无效的断点续传内容，复用匹配的 Intel 版本，并改进缓存读取与后台压缩的协调。
- **安装计划与诊断：**写入游戏文件前要求确认不确定的程序选择，报告不完整的 Intel 扫描，并拒绝无法确认完整结果的安装计划。导出日志会隐藏更多绝对路径，包括旧导出；分享前仍请检查诊断内容。

本地自动化测试覆盖这些变化。维护者曾在 RTX 4090/621.01 测试版本上观察到原生 Smooth Motion 准备，但未统计插值帧。最终 Hub 文件尚无单独真实游戏验证；RTX 50 实体硬件及原生 Vulkan 仍未验证。没有可用的已验证原件时，无法修复不完整备份。[RTX Encore 1.4.5](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.5) 为独立模组版本。
