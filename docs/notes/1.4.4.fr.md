# RTX Encore Hub 1.4.4

- **Réglages Smooth Motion natifs :** rend les commandes existantes disponibles sur RTX 40/50 avec RTX Encore 1.4.5 ou ultérieur et un pilote pris en charge. Choisissez l'API réelle du jeu et redémarrez-le. Le compteur simple 2x du mod est une estimation, pas une mesure des images interpolées.
- **Détection de l'API graphique :** reconnaît les API DirectX courantes chargées dynamiquement avant les chargeurs annexes livrés avec le jeu, notamment pour Men of War II. Cette détection statique reste probable ; vérifiez l'API réelle. Les recommandations initiales tiennent compte des fonctions disponibles et préservent les choix explicites et réglages existants.
- **Sauvegardes partagées et restauration :** améliore la migration indépendante des données vérifiables, préserve les informations de récupération lorsqu'un original manque et évite de recréer les dossiers de jeux absents. Les empreintes des sauvegardes et les contrôles de restauration restent obligatoires.
- **Téléchargements et cache :** vérifie plus strictement la fin des téléchargements, reprend depuis zéro les reprises invalides, réutilise les versions Intel correspondantes et coordonne mieux la lecture du cache avec sa compression en arrière-plan.
- **Plans et diagnostics :** demande confirmation d'un exécutable incertain avant les opérations écrivant dans le jeu, signale les analyses Intel incomplètes et refuse les plans dont le résultat complet ne peut être établi. Les journaux exportés masquent davantage de chemins absolus, y compris dans les anciens exports ; relisez les diagnostics avant partage.

Les tests automatisés locaux couvrent ces changements. Le propriétaire a observé la préparation Smooth Motion native sur RTX 4090/621.01 avec un build de test, sans compter les images interpolées. Les binaires finaux du Hub n'ont pas de validation distincte en jeu ; les RTX 50 physiques et Vulkan natif restent non qualifiés. Une sauvegarde incomplète ne peut pas être réparée sans original vérifié disponible. [RTX Encore 1.4.5](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.5) est une version distincte du mod.
