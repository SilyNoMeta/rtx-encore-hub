# RTX Encore Hub 1.2.0

[English](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0.md) · [Français](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0.fr.md) · [简体中文](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0.zh-CN.md)

包含 1.2.0-beta.1 的全部内容。**XeSS / XeFG 仍属高度实验性。** 请预期可能出现错误、崩溃、画面伪影，以及不同游戏和图形 API 之间的行为差异。欢迎报告问题：在 RTX Encore Hub 中打开游戏的 **健康** 页面，选择 **生成诊断包**，检查并移除个人信息后，将诊断压缩包附加到 [RTX Encore issue](https://github.com/SilyNoMeta/rtx-encore/issues/new/choose)。Hub 不会自动上传该压缩包。

## 游戏库

- **收藏**：独立的收藏行，每张游戏卡片上的紧凑操作；可直接从卡片启动游戏。
- **可选托盘模式**：关闭窗口后 Hub 可留在通知区域，再次打开时游戏库会恢复到原来的位置。
- 标题栏搜索可直接筛选游戏库。
- Hub 会在本地保留游戏的原始文件，并缓存它提供的模组压缩包，还原和重新安装时需要的下载更少。

## 搭配 RTX Encore 1.2.0

- **NVIDIA 621.01 驱动上的 Smooth Motion**（RTX 30），需要 RTX Encore 1.2.0 或更高版本。游戏中的旧版模组会被提示需要 1.2.0。
- **Force Smooth Motion 已移除**：在 Vulkan 游戏中开启 Smooth Motion 时，模组 1.2.0 始终会解除驱动的按游戏排除。在这类游戏中仍可能出现意外结果。
- **DLSS 预设和重建引擎** 在 RTX Encore 1.2.0 下现在可在游戏运行中生效，Hub 不再为它们要求重启。在 Vulkan 游戏中，请在启动前选择 XeSS。

## 1.2 的其他内容

Intel XeSS 与 XeFG 及其依赖、逐轮 Neural Rendering、共用的 HDR 输入和曝光控制、可直接打开游戏的全局搜索、可执行文件候选，以及更完整的诊断，已随 1.2.0-beta.1 推出：见[其说明](https://github.com/SilyNoMeta/rtx-encore-hub/blob/main/docs/notes/1.2.0-beta.1.zh-CN.md)。

## 兼容性与限制

Intel、共用输入、逐轮 NR 和提供程序策略设置需要已识别的模组 1.2.0-beta.1 或更高版本；在 621.01 驱动上使用 Smooth Motion 需要 1.2.0。旧模组保留其支持的控制项。XeFG 路径仍属实验性，取决于模组、图形 API、游戏和运行库；请求的倍率不能证明实际显示的帧数。

Hub 的改动已通过其自动化测试和替代游戏文件夹进行检查。这些检查不能证明某个引擎在你的游戏中可用，也不测量显示延迟。
