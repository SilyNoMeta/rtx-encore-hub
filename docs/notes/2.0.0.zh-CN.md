# RTX Encore Hub 2.0.0

**引导安装：**首次为没有原生集成的游戏安装时，可分别选择帧生成与超分辨率，包括无。不再自动启用 Smooth Motion。更新会提供缺失依赖，并保留现有引擎选择。

**Hub 2.0.0 是一个大版本。**配合 RTX Encore 2.0.0，完全没有 DLSS 的游戏现在也能获得 DLSS、帧生成和 Neural Rendering，由 RTX Encore 专为它们编写的运动估计引擎驱动，Hub 会安装它们所需的一切。RTX Encore 和 Hub 还换上了全新的视觉形象和标志，RTX Encore 也开设了自己的 Discord。

**RTX Encore 的 Discord 服务器现已开放。** 欢迎分享 2.0.0 的测试结果、交流设置，或就模组和 Hub 寻求帮助。[加入 Discord](https://discord.gg/Zwmq4Xc2Br)。

- **没有 DLSS 的游戏：**RTX Encore 2.0.0 可以在本身不带 DLSS 的游戏中，对游戏显示的画面运行 DLSS（DLAA，或放大到屏幕分辨率）或 Intel XeSS、神经渲染和帧生成。帧生成为 DirectX 11、DirectX 12 和 Vulkan 上的 NVIDIA DLSS Frame Generation，或 Intel XeFG（DirectX 12、Vulkan 和 DirectX 11 上 X2 至 X6），取决于模组菜单中选择的引擎，倍率可在游戏中更改。在这类游戏中，安装或更新模组 2.0.0 时会一并带来这些功能所需的全部文件：模组旁的 `nvngx_dlss.dll` 和 `nvngx_dlssnr.dll`，与以前一样的 Intel 运行库；当游戏既没有自己的帧生成也没有自己的 Streamline 时，还会在可执行文件旁放置 DLSS Frame Generation 所需的六个文件（NVIDIA SDK 中的 Streamline 2.14.16 和 `nvngx_dlssg.dll` 310.9.16，均为指定版本，NVIDIA 签名已验证）。未选择的功能保持关闭：请在模组菜单或**此游戏的全部设置**中逐项开启。Hub 绝不会覆盖游戏自身的文件，自带 DLSS 的游戏不会收到这些文件，**还原游戏**会移除所添加的内容。
- **Hub 中的相应设置：**无 DLSS 游戏的超分辨率、其输出（**游戏分辨率（DLAA）**或**屏幕分辨率**）和引擎（DLSS 或 XeSS）、运动估计（默认 **RTX Encore**，以及**着色器 (vort)**、**Optical Flow (质量)**、**Optical Flow (快速)**）、无游戏 DLSS 时的 NR 和无帧生成游戏的帧生成。每项设置都会说明此游戏自带什么、开启后 Hub 会添加什么；选择 XeSS 会在同一次更改中带来 Intel 运行库。游戏页面新增**没有 DLSS 的游戏**部分，列出 DLSS Frame Generation 所需的文件及其状态，并提供写入缺失文件的复选框。命令行中，`setup --set` 和 `update <游戏>` 也会带来相同的文件。
- **平滑 X3 / X4，自动：**配合模组 2.0.0，可选择**自动**（模组的默认值）、**开启**或**关闭**。自动模式下，模组会在 X3 及以上测量生成帧到达驱动的方式，并为每个游戏学习是否应由 Streamline 安排节奏；设置页面会显示学到的结果，**重新测量**会将其清空。共享配置只保存开启或关闭。
- **模组菜单语言：**在**设置 → 模组菜单语言**中选择 RTX Encore 游戏内菜单的语言：**与 Hub 相同**（默认）或菜单支持的十一种语言之一。安装或更新模组 2.0.0 时，只会写入设置中尚未指定语言的游戏，因此在游戏内菜单中选择的语言会被保留。更改此偏好会写入 Hub 安装了模组的所有游戏，每次写入都可撤销；受反作弊保护的游戏保持不变。菜单没有阿拉伯语，会改用英语显示。
- **十二种语言：**除英语、法语和简体中文外，Hub 现在还支持德语、西班牙语、荷兰语、波兰语、巴西葡萄牙语、越南语、俄语、阿拉伯语（从右到左）和日语，托盘菜单也包括在内。请在**设置 → 界面语言**中选择。感谢 [@Matarto](https://github.com/Matarto) 提出请求（[#12](https://github.com/SilyNoMeta/rtx-encore-hub/issues/12)）。
- **全新标志：**深色底板上一个青柠色漆面陶瓷质感的斜切字母 E，另有浅色版本。Hub 的图标、标题栏、托盘、安装程序和快捷方式都会显示它。
- **浅色主题：**在**设置 → 主题**中可选择深色、浅色或跟随 Windows，在**设置 → 图标**中可选择标题栏、任务栏和通知区域使用深色或浅色标志（默认跟随主题）。
- **模组 2.0.0：**安装并更新 RTX Encore 2.0.0。以上设置只在模组 2.0.0 或更新版本旁显示和写入；较旧的模组保留其读取的设置。

无 DLSS 游戏的相关功能为实验性：HUD 会与画面一起处理，开启或关闭无帧生成游戏的帧生成需要重启游戏。参见模组的[没有 DLSS 的游戏](https://github.com/SilyNoMeta/rtx-encore/blob/main/docs/GAMES-WITHOUT-DLSS.zh-CN.md)页面。已验证引擎的自动化测试、界面检查、mod 契约、编译、嵌入版本、更新签名及发布文件；尚未在真实游戏中测试这些文件。最终文件未单独进行交互复测。
