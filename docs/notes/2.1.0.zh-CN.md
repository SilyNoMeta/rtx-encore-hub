# RTX Encore Hub 2.1.0

**XeFG 稳定游戏帧节奏：**RTX Encore 2.1.0 的新设置位于**此游戏的全部设置**中，默认开启。从 X3 起，它以略低于游戏可维持帧率的固定节奏开始游戏的每一帧，使 XeFG 生成帧之间的镜头运动保持均匀；代价是少量 FPS，游戏运行时即可生效。Hub 仅在模组 2.1.0 或更高版本旁显示并写入该设置，共享配置也会包含它。

**选择要安装的内容：**每次安装和游戏更新现在都会先打开**选择组件**，再显示文件预览。可分别选择模组、每个 NVIDIA DLL（Super Resolution、Ray Reconstruction、Frame Generation、Neural Rendering）、一套 Streamline 插件、Intel XeSS / XeFG / XeLL 以及可选的 DLSS 帧生成文件；每个 DLL 都会注明用途。未勾选的文件完全保持原样，因此拒绝较新 Streamline 插件的游戏可以保留自己的版本。已安装游戏的页面上仍保留**选择组件**，之后可补装最初跳过的组件而无需重新安装模组；批量更新会遵循每个游戏的选择。感谢 [@o5-null](https://github.com/o5-null) 关于使命召唤的报告说明了这一需求（[rtx-encore#110](https://github.com/SilyNoMeta/rtx-encore/issues/110)）。

- **模组 2.1.0：**安装和更新 [RTX Encore 2.1.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v2.1.0)：XeFG 在 X3 及以上倍率下保持流畅、添加的帧生成使用游戏自身的深度和运动数据、DirectX 11 和 Vulkan 中 XeFG 可使用 Tensor Core，并修复了博德之门 3、最终幻想 VII 重生、极限竞速：地平线 6、天国：拯救、Islands of Insight 和刺客信条：黑旗 Resynced 中的问题。

已验证 Hub 的自动化测试、界面检查、模组契约、构建、内嵌版本、更新签名和分发文件。最终二进制文件未单独进行交互式复测。
