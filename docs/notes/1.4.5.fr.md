# RTX Encore Hub 1.4.5

- **Moteur de génération d’images :** ajoute le choix NVIDIA DLSS-FG pour les jeux à FG Intel natif compatibles comme Mirage. Jeu conserve le moteur natif ; XeFG garde le remplacement Intel existant. Le FSR reste natif. Redémarrez le jeu après un changement de moteur FG.
- **Reflex :** ajoute Jeu / On / On+Boost et le rapport de latence des images rendues. La demande ne diminue pas le mode du jeu et se suspend en Dynamic ou lorsque XeLL gère la latence ; aucun gain de latence n’est garanti.
- **Modèles communautaires :** importent et exportent les nouveaux choix FG/Reflex et l’affichage de latence, avec un validateur en ligne synchronisé. Les profils existants et les autres réglages sont conservés.

À utiliser avec [RTX Encore 1.4.6](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.4.6) et les runtimes compatibles. Les tests locaux couvrent réglages, aller-retour des profils et validation ; les binaires finaux du Hub n’ont pas de validation distincte en jeu.
