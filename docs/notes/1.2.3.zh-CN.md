# RTX Encore Hub 1.2.3

- **干净重装，保留设置。** 由 Hub 管理的游戏页面新增重装操作：先展示方案，再重新创建模组及其受管理的运行库，并原样保留设置及注释。可在健康页面恢复重装前的安装。如果缺少运行库的精确来源或存在未知文件，操作会在写入游戏文件前被拒绝。感谢 [@wer2357666](https://github.com/wer2357666) 的建议和报告（[#4](https://github.com/SilyNoMeta/rtx-encore-hub/issues/4)）。这是一项修复选项，并非已确认解决报告中的 GTA V Enhanced 崩溃。
- **锐化控制与共享偏好。** 配合兼容的 RTX Encore 版本，可选择 Off、Game 或 Custom，强度为 0–100%，Custom 默认 30%。此偏好可以包含在共享配置中。这些控制项现已随 Hub 发布；对应的模组功能由 RTX Encore 1.2.2 提供。较高强度可能放大噪点和光晕。

Hub 与 RTX Encore 模组版本独立。本次发布不修改模组。自动化检查使用虚拟游戏文件夹，不能证明实际游戏兼容性、画质或性能。Intel XeSS 和 XeFG 仍为实验性功能。
