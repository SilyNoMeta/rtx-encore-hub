# RTX Encore Hub 1.5.3

- **RTX 30/40/50 Tensor 控制：**随匹配 mod 版本提供独立的 XeSS 与 XeFG Tensor Core 开关。RTX 30 和 RTX 50 需要 mod 1.5.3；RTX 40 控制保留原版本范围。Mod 1.5.3 准入 NVIDIA 621.01 与实验性 621.12 热修复驱动。游戏内验证仍仅覆盖较早 RTX 4090 / 621.01 配置。
- **V-Sync 游戏 / 关闭 / 开启：**提供 mod 1.5.2 的三选项控制，并迁移旧的关闭 V-Sync 配置。适用于兼容 DirectX 游戏；不适用于 Vulkan 和 XeSS-FG，强制开启可能增加延迟。
- **RR 预设 F：**在兼容运行库允许时新增 Ray Reconstruction 选项。感谢 [@dm1z0r](https://github.com/dm1z0r) 的建议（[#95](https://github.com/SilyNoMeta/rtx-encore/issues/95)）。
- **契约与社区配置：**同步 mod 1.5.3 的设置、迁移、硬件/版本要求及共享配置验证。

未重新运行完整自动化测试套件。已验证针对性检查、mod 契约、编译、嵌入版本、更新签名及发布文件。最终文件未单独进行交互复测。
