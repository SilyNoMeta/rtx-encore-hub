# RTX Encore Hub 1.5.0

- **XeSS 与 XeFG Tensor Core：**为模组 1.5.0 的新 NVIDIA Tensor 选项提供两个独立即时开关，均属实验性质且默认关闭。初始验证范围为 RTX 4090、NVIDIA 621.01、DirectX 12 和 Hub 提供的兼容 Intel 运行库。
- **即时控制：**XeSS 在下次执行时切换；XeFG 在命令重新记录时切换，并在初始化容量内支持固定 X2–X6。安装模组或切换 FG 引擎仍需重启游戏。
- **社区配置：**独立保留两个 Tensor 选项；在线验证器接受新字段。配置值不代表硬件兼容。
- **Hub 更新：**检查或下载更新遇到临时网络错误时有限重试。仍须验证签名，不重复安装。

控制项要求 **模组 1.5.0 或更新版本**，避免为已发布的 1.4.7 提供不存在的选项。Tensor 准备未通过时保留标准 Intel 路径；执行故障后须重启。尚未证明 XeFG 的普遍 FPS 或延迟收益。最终 Hub 二进制文件未单独在游戏内复测。[模组 1.5.0](https://github.com/SilyNoMeta/rtx-encore/releases/tag/v1.5.0)。
