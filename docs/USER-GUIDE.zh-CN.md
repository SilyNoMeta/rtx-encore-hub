# 使用 RTX Encore Hub

[English](USER-GUIDE.md) · [Français](USER-GUIDE.fr.md) · [返回项目](../README.zh-CN.md)

RTX Encore Hub 把 [RTX Encore](https://github.com/SilyNoMeta/rtx-encore) 安装到您的游戏中，让模组和 NVIDIA DLL 保持最新，检查游戏装上模组后能否正常启动，并且随时可以还原。界面跟随 Windows 的语言：法语、英语或简体中文；其他语言使用英语。本指南使用应用的中文标签。

## XeSS 与 XeFG Tensor Core（1.5.0）

配合 **RTX Encore 1.5.0 或更新版本**，为 **XeSS Tensor Core** 选择 XeSS 重建，为 **XeFG Tensor Core** 选择 XeFG 引擎。两个开关相互独立、属实验性质且默认关闭。初始验证范围为 **RTX 4090、NVIDIA 621.01、DirectX 12 和 Hub 提供的 Intel 运行库**，不代表其他配置也支持。

两开关均可即时生效：XeSS 在下次执行时，XeFG 在命令重新记录时。支持的固定 XeFG X2–X6 也可在初始化容量内即时切换。安装新模组前请关闭游戏；切换 FG 引擎仍需重启。准备未通过时保留标准 Intel 路径；Tensor 执行故障后须重启。社区配置保留两个选项，但导入不会使其他显卡或驱动获得支持。

较早巫师 3 场景测量显示 XeSS GPU 时间约减少 30.7%，渲染源帧 FPS 约提高 2.8–3.2%；后续最终重建更改仅有确定性重放验证，没有新的游戏内对比。尚未证明 XeFG 的普遍 FPS 或延迟收益。[完整条件与测量](https://github.com/SilyNoMeta/rtx-encore/blob/main/docs/INTEL-ENGINES.zh-CN.md)。


## 使用 1.2.2

**XeSS / XeFG：高度实验性。** 这部分集成的开发过程非常艰难，也相当折腾 :) 请预期可能出现错误、崩溃、画面伪影，以及不同游戏和图形 API 之间的行为差异。欢迎报告问题：在 RTX Encore Hub 中打开游戏的 **健康检查** 页面，选择 **生成诊断包**，检查并移除个人信息后，将诊断压缩包附加到 [RTX Encore issue](https://github.com/SilyNoMeta/rtx-encore/issues/new/choose)。请注明选择的引擎、图形 API 和请求的倍率。Hub 不会自动上传该压缩包。

稳定版 1.2.2 可通过 Stable 更新通道获取；Candidate 通道还包含预发布版本。

Intel、共用输入和逐轮 NR 设置需要模组 1.2.0-beta.1 或更高版本。模组 1.2.2 不再使用 NVIDIA 提供程序策略设置，Hub 会隐藏该选项；旧模组保留兼容的控制项。XeFG 仍属实验性，取决于模组、图形 API、游戏和运行库。请求的倍率不能证明实际显示的帧数。

### Intel 引擎及依赖

搭配 RTX Encore 1.2，可在模组支持的场景中选择 XeSS 重建或 XeFG 帧生成。Hub 会随模组安装并验证 Intel 文件及许可证，在同一操作中备份和还原它们。文件已安装不能证明引擎已激活。

### 逐轮调整 Neural Rendering

四轮处理中的每一轮都可以调整强度、局部色调、局部结构、皮肤结构和角色遮罩，也可以继承全局设置。强度设为零仍会运行该轮处理，不会消除其计算开销。

自 RTX Encore 1.2.0-beta.1 起，NR 还可在提供兼容线性深度输入的 Direct3D 12 游戏中于 Ray Reconstruction 之后运行。Direct3D 11 和 Vulkan 仍不支持此情况。007 First Light 路径追踪的本地测试确认 NR 可以运行；尚未测量画质和开销。偶发启动崩溃仍未解决。

### HDR 输入与曝光

共用设置 `srHdr` 和 `srAutoExposure` 跟随所选重建引擎，默认跟随游戏，需要重启生效。HDR 输入不会开启显示器 HDR，也不会将 SDR 转换为 HDR。

不了解游戏输入格式时，请将两项设置保留为 `game`。错误的 HDR 输入设置会损害画质。自动曝光可能改善与曝光有关的拖影，但并非通用修复；某些 DLSS 模型会强制启用。XeSS 自动曝光有 GPU 开销，不推荐用于 LDR。XeSS Vulkan 的 LDR 输入与手动曝光组合仍不受支持。Ray Reconstruction 和帧生成保持不变。

提供程序策略仅适用于仍使用该选项的旧模组，并且保留在本地游戏设置中。RTX Encore 1.2.2 忽略旧的 `providerPatchPolicy` 设置。NVIDIA 兼容性不再要求预设版本列表；Intel 运行库检查保持不变。这些策略控制项不会在社区配置中共享。

使用 XeFG 时，修改 FPS 上限需要重启游戏。较高 XeFG 倍率的可变帧间隔属于实验性功能。FPS 上限不能证明源帧节奏。

## 安装 Hub

从发布页面下载 `RTX-Encore-Hub-Setup-<版本>.exe` 并运行。它只为您的账户安装，**不需要管理员权限**，位置是 `%LOCALAPPDATA%\Programs\RTX Encore Hub`。无需事先安装其他任何东西。

安装程序没有签名：第一次运行时 Windows 可能显示 SmartScreen 警告。每个发布版本都给出安装程序的 SHA-256；如果您想确认文件，可以对比它。

Hub 在启动时检查自身更新，之后每天一次。**更新**页面显示新版本及其说明；**更新并重新启动**会下载安装程序、校验其摘要、运行它并重新启动 Hub。您可以选择**稍后**，或**忽略此版本**。如果某个游戏正在安装，更新会等它结束。更新或卸载已安装的程序会保留设置和还原数据。

**便携版。** `RTX-Encore-Hub-Portable-<版本>.zip` 无需安装：将其解压到您有写入权限的文件夹（不要放在 Program Files 下），然后运行 `rtx-encore-hub.exe`。旁边的 `portable.txt` 文件让 Hub 将自身状态保存在相邻的 `data` 文件夹中：请保留这个文件夹。原始文件和历史备份共享保存在该数据文件夹中；移动或更新便携版时请保留它。便携版不会自行更新：**更新**页面中的**下载便携版**会打开发布页面；关闭 Hub，然后用新压缩包中的 `rtx-encore-hub.exe` 和 `encorehub-elevated.exe` 替换现有文件。

## 找到您的游戏

**游戏库**汇集本机上 Steam、Epic 和 GOG 已安装的游戏。其他游戏：

- **设置 → 游戏文件夹 → 添加文件夹…**：其中每个包含可识别可执行文件的子文件夹都会成为一个游戏；
- **添加游戏**：直接指定游戏的可执行文件。

模组会放在绘制游戏的程序旁边：如果游戏由启动器启动（GOG 版 The Witcher 3 启动的是 `REDprelauncher.exe`），Hub 会选用启动器所启动的游戏；如果游戏通过 RTX Remix 运行，模组会放在游戏 `.trex` 文件夹中的 `NvRemixBridge.exe` 旁边。

磁贴用一个图标和一个词说明游戏的状态：未安装、已安装、可更新、被游戏更改、失败。搜索（`Ctrl+F`）忽略重音和标点；筛选器可以只显示某一种图形 API；`F5` 重新读取文件夹。侧栏会显示您的机器：显卡、显存、驱动、屏幕。

游戏页面无法确定可执行文件时，请检查候选程序并选择游戏本身，也可以恢复自动选择。标题栏的全局搜索也可查找游戏库中的游戏。

## 阅读游戏页面

选择一个磁贴。

- **这里能做什么**：对帧生成、DLSS Super Resolution、Smooth Motion 和 Neural Rendering，说明该功能在您的显卡和驱动上是否可行；不可行时说明原因。这是根据文件和驱动推断的，不是游戏内的实证。
- **NVIDIA DLL**：逐个比较游戏中的版本、本机已有的最佳副本以及 Hub 的建议。本机没有的 DLL 会被下载：DLSS、Ray Reconstruction 和帧生成来自 NVIDIA 在 GitHub 上的官方仓库，Neural Rendering 的 DLL 来自本项目的存储桶。**只有带有效 NVIDIA 签名的 DLL 才会被接受**；Neural Rendering 的 DLL 还必须正是模组所要求的那个构建。
- **当前 NVIDIA 下载**：内置目录提供 DLSS SR、RR、FG 和 NR 310.9.16，以及 Streamline 插件 2.14.16。文件需要更新的模组时，Hub 会说明原因，而不是提供旧版本下载。游戏中已有的更新 DLL 会保留。FG 预设 C 需要兼容的 310.9.16；Lite 合成有画质取舍，不使用普通保护设置或界面重组。
- **Streamline 插件**作为匹配的整套一起获取。保留游戏自身的 `sl.interposer.dll`，页面会单独显示其版本并说明与插件的差异。
- **当前 NVIDIA 下载**：内置目录提供 DLSS SR、RR、FG 和 NR 310.9.16，以及 Streamline 插件 2.14.16。文件需要更新的模组时，Hub 会说明原因，而不是提供旧版本下载。游戏中已有的更新 DLL 会保留。FG 预设 C 需要兼容的 310.9.16；Lite 合成有画质取舍，不使用普通保护设置或界面重组。
- **在某个游戏中取消勾选的内容会在该游戏中保持不变**：在游戏页面上取消勾选的 NVIDIA DLL、Streamline 插件或默认预设会针对该游戏被记住。页面会提醒您，“全部更新”不会改动它们，重新勾选即可恢复。
- **DLSS Super Resolution 模型**：Hub 把所选模型写入该游戏的 `rtx-encore.jsonc`（`dlssSrPreset`），RTX Encore 在游戏启动时应用它。Hub 从不修改该游戏的 NVIDIA 驱动配置文件；如果该配置文件自行强制了某个模型（例如通过 NVIDIA 应用设置），页面会注明，因为在低于 1.1.0 的模组下它可能优先。

- **起始设置**：针对您显卡的建议。帧生成倍数默认由游戏决定；也可以选择 ×2、×3 或 ×4。
- **代理文件名**：游戏加载模组所用的文件名（`version.dll`、`dxgi.dll`、`winmm.dll`、`dinput8.dll`）。页面会逐一说明游戏是否会加载它以及原因：可执行文件导入了什么、Windows 是否对该游戏应用了兼容性修复、是否已有其他工具占用、上次启动的结果，以及社区配置的报告。推荐的文件名由此得出；您可以通过一次可撤销的操作改用其他文件名。在装有 ASI 加载器的游戏中，模组也可以作为插件 `rtx-encore.asi` 加载。已占用某个文件名的工具绝不会被覆盖。Windows 对游戏应用的兼容模式可以在其页面中移除：对您的帐户直接移除；对所有帐户，Windows 会先请求管理员权限。Hub 会记录它移除的内容，**恢复**可将其还原为原样。

**反作弊。** 当 Hub 识别出反作弊（EasyAntiCheat、BattlEye……）时，磁贴和页面都会写出它的名字。您的账号可能被封禁，模组也可能无法加载：在您于确认窗口中接受这一风险之前，不会向该游戏写入任何内容。检测依据已知文件，可能漏掉某些保护。

## 安装或更新

页面的主按钮会打开一个三步向导。

1. **检查**：游戏包含什么，您的机器允许什么。
2. **将要写入的内容**：确切的清单，包括现在是什么、之后是什么。此时还没有写入任何东西。每个原始文件都会先保存到 Hub 数据文件夹。
3. **启动时验证**（如果您保留勾选）。

安装要么全部完成，要么完全不做：如果某次写入失败，一切都会恢复原状。如果 Hub 在中途被终止（断电、崩溃），它会在下次启动时、在做任何其他事情之前撤销被中断的安装，并告诉您。

如果游戏文件夹拒绝您的账户写入，Windows 会**仅为这一次操作**请求管理员权限。获得权限的不是 Hub，而是一个小程序：它只执行您刚刚接受的计划，并重新核对每个文件。

游戏库中的**全部更新**会更新所有装有旧版模组的游戏。“同时更新 NVIDIA DLL 和 Streamline 插件”默认勾选：每个游戏会同时获得其页面默认采用的内容，即在**设置 → 安装时的默认值**中选择的版本，以及游戏尚未自行设置时您的默认预设。如果某个游戏的 NVIDIA 文件无法获取，它的模组仍会更新，界面会指出是哪个游戏。每个游戏有自己的事务，在其页面上使用“还原游戏”可全部恢复；带反作弊的游戏会被跳过。

## 检查游戏是否正常启动

游戏页面顶部的**启动游戏**会像其启动器那样启动游戏，不做任何观察。

**健康检查 → 启动并验证**会启动游戏并观察它的第一分钟：进程是否保持运行，模组是否加载，它的日志说了什么。结果是一句话（“一切正常”，或用白话说明原因），然后是各项发现：显卡和架构是否识别、驱动是否识别、模块是否被接受、Neural Rendering 是否就绪。如果游戏以模组的文件名加载了另一个文件，或从未请求该文件名，页面会说明并建议改用的文件名；如果旧的 dlssg_for_sm86 模组仍在游戏中加载，页面也会提醒。

如果游戏在第一分钟内停止，或模组没有加载，页面会提供一键**还原**到之前的状态。同一次安装连续失败两次后，还原会成为主按钮。**生成诊断包**会生成一个文本文件压缩包，其中不含您的用户名和机器名，请先阅读，再自行附到问题反馈中：Hub 不会发送任何东西。

这项验证说明游戏能启动、模组能加载。它不评判画面，也不评判性能。

压缩包包含模组文本日志目录、设置和游戏目录文件列表。Hub 会隐藏识别到的用户名和计算机名。提交问题前请检查压缩包；它不会自动发送。

## 还原

健康检查页面上的**此游戏的备份**按时间列出 Hub 的每一次操作。您可以回到某次操作之前的状态，或回到 Hub 做任何改动之前的状态（**还原游戏**）。

之后被游戏、启动器或其他工具更改过的文件绝不会被覆盖：它会保持原样并被报告。还原到 Hub 进行任何改动之前的状态会保留已修改的 `rtx-encore.jsonc`；还原到某次操作之前时，替换已修改的设置需要确认。

卸载会移除 Hub 记录的模组和运行库文件，并还原原有文件。私有目录 `rtx-encore-runtimes/intel` 和 `rtx-encore-runtimes` 为空时会被删除。`rtx-encore-logs` 中的日志和已修改的设置会保留；这些文件的存在不代表模组仍已安装。如果不再需要，可以自行删除日志和设置。包含其他文件的运行库目录会保留。

手动放入的模组副本可以被识别，但 Hub 只对自己写入的内容保有原始备份。

## 游戏更新之后

如果游戏的更新或修复替换了安装的文件，页面会写明：**游戏更改了安装内容**。

- **重新应用**：模组缺失时重新写入，并重新写入 Hub 仍有更好副本的 NVIDIA DLL。游戏带来的更新的 DLL 会保留。
- **忘记**：保留游戏的文件原样，并不再跟踪它们。

## 调整模组

游戏页面会在本机记住上次选择的预设、倍率和选项。只有点击应用后才会写入游戏；可用选项会根据游戏当前的组件重新检查。滚动游戏页面或全部设置时，返回和应用按钮始终可用。

**此游戏的全部设置**通过一个按文件各部分排列的表单编辑 `rtx-encore.jsonc`。每项设置都带有说明、默认值，以及在适用时的“需要重启”。对您的显卡无效的设置会变灰并说明原因。DLSS 预设取决于游戏中的 DLL：表单只提供已安装的 DLL 支持的预设，并说明其余预设缺失的原因；例如，帧生成预设 C 只存在于 DLSS-G 310.9.16 中。注释和 Hub 不认识的键会原样保留。

如果游戏在附加模组的游戏内菜单时启动即关闭（Star Wars Outlaws），可以不使用该菜单：在“兼容性”中开启 `disableInGameMenu`，然后在这里更改设置。如果游戏在加载模组后第一分钟内关闭，**启动并验证**会提供**不带游戏内菜单重新启动**，替您完成这一设置。

在您看到更改之前不会写入任何东西。最后一次更改可以一键撤销。**此游戏的配置**把当前生效的设置按名称保存，并可一键切换回去。

## 社区配置

社区自 1.0.0-rc.2 起开放。它仍是实验性的、测试较少，并且一开始是空的：最早的配置将由您发布。

- 游戏的配置**按与您机器的接近程度排序**，并说明原因：相同显卡、相同分辨率、驱动较旧……默认只显示在您这一系列显卡上制作的配置。
- 页面先显示十来个配置；**显示更多配置**会继续添加。**筛选**可以缩小列表：我的配置、相同显卡、相同分辨率、已有他人确认、官方、有测量、Neural Rendering、Smooth Motion、固定或动态 FG 倍率。只提供能区分这些配置的筛选项。
- **导入**会先逐个部分显示将要改变的内容。键盘快捷键只有在您要求时才会导入；诊断设置从不导入。您之前的设置会以“导入前”为名保存，并且一个按钮就能把文件恢复得与原来完全一样。
- **点赞**、**在我这里可用**和**举报**都只需一次点击，并且可以撤回。
- **发布我的配置**：机器和版本信息由 Hub 填写；您补充 DLSS 模式、光线追踪级别和备注。**所有将要发出的内容都会在发送前原样显示。** 不含文件路径、用户名或机器名：包含这些内容的备注会被拒绝。

没有账号。密钥在您的机器上生成并留在那里；您只需选择一个昵称。

## 更新模组

**设置 → RTX Encore 来源**：RTX Encore 仓库的公开发布版本（通过 SHA-256 校验），或包含模组构建的本地文件夹。在**更新**页面，**模组通道**的选择方式与 Hub 的相同：**稳定版**只提供正式版本，**候选版**还跟随预发布版本。在您做出选择之前，本身为预发布版的 Hub 会对自身和模组都跟随候选通道。该页面会说明每个游戏装有哪个版本的模组，并显示每个发布版本的说明。

## 数据、网络与隐私

原始文件和操作历史以经过校验的共享 ZIP 备份保存在 Hub 数据文件夹中。只有字节内容和完整 SHA-256 相同的文件才共享副本；版本号相同但内容不同的 DLL 仍分别保存。只有不再被任何游戏、保留的历史操作或恢复过程使用时，才清理共享副本。历史记录仍最多保留八次操作；下载的运行库存储保持独立。

从 1.0.x、1.1.x 或 1.2.x 升级后首次启动时，Hub 会自动优化所有已保存游戏的备份，包括不再显示于游戏库中的游戏。原始文件和历史仍可还原，设置保持不变。仅在转换提交后，才删除旧 Hub 目录及游戏内 `rtx-encore-backups` 中已验证的副本。未知或被修改的文件会保留。可在两个游戏之间停止；中断、无法访问的游戏或被锁定的文件将在下次启动时重试。若清理因权限受限，可在游戏库点击**以管理员权限重试**；Windows 会在仅针对该游戏的辅助程序运行前请求许可。

只要任何游戏仍需要还原，就请保留完整的 `%LOCALAPPDATA%\EncoreHub` 文件夹，便携版则保留旁边的 `data`。其中现已包含多个游戏共享的原始文件，以及设置和历史。迁移后的状态需要 Hub 1.2.4 或更高版本才能还原；旧版 Hub 会拒绝新的引用格式。**设置 → 存储空间** 显示应用程序、备份、已下载运行库、RTX Encore 压缩包、游戏封面、日志及其他 Hub 数据所占空间，以及仍保存在游戏目录中的旧备份；部分扫描会明确提示，此时显示的总量为最小值。卸载已安装的程序会保留这些数据，删除数据则会失去对应还原副本。

模组缓存只保留 stable 和 candidate 通道当前提供版本的原始 ZIP。在线确认发布列表后，将删除旧版本和旧的解压缓存文件夹。因此，旧解压缓存可能需要重新下载一次。安装源文件仅临时解压。

在 NTFS 上，已下载的 NVIDIA、Intel 和 Streamline 运行库 DLL 使用 Windows LZX 压缩。读取游戏库后，已有缓存 DLL 也会在后台压缩，即使自动下载运行库已关闭；不会删除缓存版本。Windows 在读取时透明提供原始字节，安装和签名验证保持原有行为。存储空间统计会计入运行库压缩后的大小；资源管理器的**占用空间**显示节省量，而**大小**不变。不支持的卷（包括 exFAT 便携式存储设备）、锁定的文件和无法节省空间的文件保持原样；压缩失败不会阻止安装。

Hub 会联系以下站点，无需账号，也不发送任何属于您的信息：

- GitHub：获取模组的发布版本、Hub 的发布版本、NVIDIA 的 DLL 以及 Streamline 插件；
- `encore-dl.nometa.fr`：获取 Neural Rendering 的 DLL、您选择改用的可选版本、来源列表，以及您打开社区页面时的社区配置；
- `encore-community.nometa.fr`：仅在您发布、撤下、点赞、确认或举报配置时联系，发送的是您已阅读的内容，并由本机密钥签名。要关闭社区，请在 `%LOCALAPPDATA%\EncoreHub\settings.json` 中写入 `"Community": "off"`；
- Steam 和维基百科：查找缺失的封面，游戏标题会发送给它们。**设置 → 封面图片**可以关闭这项查找。

Hub 将默认选择的 NVIDIA 下载保存在自身数据目录中，并复用本机已验证且完全相同的副本。下载量和磁盘占用取决于组件。启动预下载选项仅控制 NVIDIA 文件；兼容模组所需的 Intel 文件仍会在安装或更新该模组时获取。

没有任何遥测。

## 键盘与屏幕阅读器

所有操作都可以用键盘完成。`Ctrl+F` 跳到搜索，`F5` 重新读取文件夹，`Alt+向左键` 返回。每种状态都用文字表达，而不只靠颜色。

## 遇到问题？

如果无法打开游戏页面，请使用**设置 → Hub 诊断 → 导出 Hub 日志**，或出错游戏页面上的导出按钮。资源管理器会显示 ZIP 文件。日志仅保存在本机，并自动轮换（最多三个文件，每个约 2 MiB），包含 Hub 版本、命令错误和无法读取的游戏数据。也可在 `%LOCALAPPDATA%\EncoreHub\logs` 中找到，便携版则位于旁边的 `data\logs`。分享前请检查压缩包，其中可能包含游戏名称和安装路径。不会自动上传。

请提交[问题反馈](https://github.com/SilyNoMeta/rtx-encore-hub/issues/new/choose)，写明 Hub 版本、游戏、启动器、显卡、驱动以及重现问题的步骤。请在阅读后附上健康检查页面准备的诊断包。

## 干净重装

在由 Hub 管理的游戏中选择**干净重装**。检查拟安装的模组版本及文件，然后应用方案。此操作会重新创建模组及其受管理的运行库（包括缺失或损坏的文件），并原样保留当前设置。必须能够获得运行库的精确来源；私有运行库文件夹中的未知文件会使清理被拒绝。不会递归删除文件夹。

默认不自动启动游戏。可从**健康 → 此游戏的备份**恢复重装前的状态，历史记录保留最近八次操作。请保留完整的 Hub 数据文件夹。此修复不保证解决 GTA V Enhanced 崩溃；保留设置也会保留可能导致问题的设置。


## 重建后锐化

**Hub 1.2.3 现已提供**，需要 RTX Encore 1.2.2 或更新的兼容模组。

游戏设置提供重建后锐化。默认 Off 关闭；Game 使用游戏提供的锐化强度，未提供时不生效；Custom 可在游戏运行中调整 0–100% 的强度，默认 30%。此视觉偏好可包含在共享配置中。适用于 DLSS、DLAA、光线重建和替换 XeSS，并在启用 Neural Rendering 时于其后处理。会与游戏后续锐化叠加，高强度可能产生光晕并放大噪点。部分图形路径尚不支持，Vulkan 与实际游戏画质尚未经验证。需要包含该功能的构建，旧版模组会忽略这些设置。

## RTX Encore 1.3.0 的设置

**Hub 1.3.0 现已提供**，需要 RTX Encore 1.3.0 或更新的兼容模组。

**中央优先 NR**（实验性，默认关闭）在图像中央以全强度运行 Neural Rendering，越靠近边缘越轻：FPS 更高，边缘附近的 NR 效果更柔和。选择预设：light 让大部分图像保持全强度，balanced 为默认，strong 收益最大。custom 使用四个数值：全强度中央区域的宽度和高度、过渡长度，以及边缘保留的 NR 细节。这些设置可包含在共享配置中。

**RTX 20 的 Smooth Motion** 需要 621.01 驱动和 DirectX 12 游戏。在检测到的 RTX 20 显卡上，RTX Encore 1.3.0 至 1.5.0 可选择 **V1（测试版 1）**（默认）或 **V2（测试版 2）**：在同一场景比较两者，每次更改后重启游戏。从 RTX Encore 1.5.1 起，RTX 20 始终使用 V2，Hub 不再显示此选项。其他显卡不显示此选项，且该选项不会开启 Smooth Motion。

RTX Encore 1.3.0 已移除 OpenNR 和 Cyber Engine Tweaks 面板，Hub 不再显示相关设置。NVIDIA Neural Rendering 仍可使用。


**RTX 40/50 原生 Smooth Motion** 需要 RTX Encore 1.4.5 或更高版本及受支持驱动。启用 Smooth Motion 设置，选择实际图形 API 并重启。静态检测建议不证明当前实际渲染 API。模组的 2x FPS 计数是估算，不统计插值帧。
