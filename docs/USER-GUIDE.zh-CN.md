# 使用 RTX Encore Hub

[English](USER-GUIDE.md) · [Français](USER-GUIDE.fr.md) · [返回项目](../README.zh-CN.md)

RTX Encore Hub 把 [RTX Encore](https://github.com/SilyNoMeta/rtx-encore) 安装到您的游戏中，让模组和 NVIDIA DLL 保持最新，检查游戏装上模组后能否正常启动，并且随时可以还原。界面跟随 Windows 的语言：法语、英语或简体中文；其他语言使用英语。本指南使用应用的中文标签。

## 安装 Hub

从发布页面下载 `RTX-Encore-Hub-Setup-<版本>.exe` 并运行。它只为您的账户安装，**不需要管理员权限**，位置是 `%LOCALAPPDATA%\Programs\RTX Encore Hub`。无需事先安装其他任何东西。

安装程序没有签名：第一次运行时 Windows 可能显示 SmartScreen 警告。每个发布版本都给出安装程序的 SHA-256；如果您想确认文件，可以对比它。

Hub 在启动时检查自身更新，之后每天一次。**更新**页面显示新版本及其说明；**更新并重新启动**会下载安装程序、校验其摘要、运行它并重新启动 Hub。您可以选择**稍后**，或**忽略此版本**。如果某个游戏正在安装，更新会等它结束。更新和卸载都不会动您的设置和备份。

## 找到您的游戏

**游戏库**汇集本机上 Steam、Epic 和 GOG 已安装的游戏。其他游戏：

- **设置 → 游戏文件夹 → 添加文件夹…**：其中每个包含可识别可执行文件的子文件夹都会成为一个游戏；
- **添加游戏**：直接指定游戏的可执行文件。

磁贴用一个图标和一个词说明游戏的状态：未安装、已安装、可更新、被游戏更改、失败。搜索（`Ctrl+F`）忽略重音和标点；筛选器可以只显示某一种图形 API；`F5` 重新读取文件夹。侧栏会显示您的机器：显卡、显存、驱动、屏幕。

## 阅读游戏页面

选择一个磁贴。

- **这里能做什么**：对帧生成、DLSS Super Resolution、Smooth Motion 和 Neural Rendering，说明该功能在您的显卡和驱动上是否可行；不可行时说明原因。这是根据文件和驱动推断的，不是游戏内的实证。
- **NVIDIA DLL**：逐个比较游戏中的版本、本机已有的最佳副本以及 Hub 的建议。本机没有的 DLL 会被下载：DLSS、Ray Reconstruction 和帧生成来自 NVIDIA 在 GitHub 上的官方仓库，Neural Rendering 的 DLL 来自本项目的存储桶。**只有带有效 NVIDIA 签名的 DLL 才会被接受**；Neural Rendering 的 DLL 还必须正是模组所要求的那个构建。
- **默认采用最新版本**：对于游戏已有的 DLL，Hub 会默认采用游戏中的 RTX Encore 所支持的最新版本，NVIDIA 自己的更新也是这样做的。此前建议的版本仍可在同一行下方选用（“改用 … 的 … 而不是建议的版本”），每个勾选框都由您决定。游戏中更新的 DLL 不会被回退。NVIDIA 应用测试版附带的 DLSS 310.9.16 这一批文件就是这样准备的：搭配 RTX Encore 1.0.0-rc.1 或更高版本时默认采用；搭配模组的测试版时采用 310.9.1。帧生成 310.9.16 是唯一支持预设 C（Lite 合成）的版本：速度更快，但画质有所取舍，且没有防撕裂保护和界面重组。
- **Streamline 插件**：对于使用 Streamline 的游戏，Hub 会把它的插件换成游戏中的 RTX Encore 所支持的最新版本（“将 Streamline 插件换为 …”，默认勾选）。这些插件总是整套一起更换，不会单个更换。游戏的 interposer（`sl.interposer.dll`）从不被替换，NVIDIA 自己的更新也是如此；页面会显示它的版本，并在它与所选插件的版本不同时提醒您。2.14.1 来自 NVIDIA 的正式版 SDK；来自 NVIDIA 应用测试版的 2.14.16 搭配 RTX Encore 1.0.0-rc.1 或更高版本时采用。
- **为所有游戏统一选择一次**：在**设置 → 安装时的默认值**中，您可以指定 Hub 默认采用的内容：Streamline 插件的版本，DLSS、Ray Reconstruction 和帧生成的版本（“模组支持的最新版本”“不替换”或某个版本），以及您的 DLSS 预设。每个游戏页面都从这些选择开始，您可以针对该游戏更改。这样选择的预设只会写入尚未自行设置的游戏，并且仅当该游戏的 DLL 支持它时才写入；页面会用“写入您的默认预设”勾选框说明这一点。
- **在某个游戏中取消勾选的内容会在该游戏中保持不变**：在游戏页面上取消勾选的 NVIDIA DLL、Streamline 插件或默认预设会针对该游戏被记住。页面会提醒您，“全部更新”不会改动它们，重新勾选即可恢复。
- **DLSS Super Resolution 模型**：Hub 可以像 NVIDIA 的工具那样，把所选模型写入该游戏的驱动配置文件。在您的驱动上还没有在游戏中确认其效果之前，页面会注明“尚未在游戏中确认”。
- **起始设置**：针对您显卡的建议。帧生成倍数默认由游戏决定；也可以选择 ×2、×3 或 ×4。
- **冲突**：另一个工具已占用模组要使用的文件名。Hub 不会覆盖它；它会换一个名字，或告诉您没有可用的名字。

**反作弊。** 当 Hub 识别出反作弊（EasyAntiCheat、BattlEye……）时，磁贴和页面都会写出它的名字。您的账号可能被封禁，模组也可能无法加载：在您于确认窗口中接受这一风险之前，不会向该游戏写入任何内容。检测依据已知文件，可能漏掉某些保护。

## 安装或更新

页面的主按钮会打开一个三步向导。

1. **检查**：游戏包含什么，您的机器允许什么。
2. **将要写入的内容**：确切的清单，包括现在是什么、之后是什么。此时还没有写入任何东西。每个被替换的文件都会先备份到游戏文件夹之外。
3. **启动时验证**（如果您保留勾选）。

安装要么全部完成，要么完全不做：如果某次写入失败，一切都会恢复原状。如果 Hub 在中途被终止（断电、崩溃），它会在下次启动时、在做任何其他事情之前撤销被中断的安装，并告诉您。

如果游戏文件夹拒绝您的账户写入，Windows 会**仅为这一次操作**请求管理员权限。获得权限的不是 Hub，而是一个小程序：它只执行您刚刚接受的计划，并重新核对每个文件。

游戏库中的**全部更新**会更新所有装有旧版模组的游戏。“同时更新 NVIDIA DLL 和 Streamline 插件”默认勾选：每个游戏会同时获得其页面默认采用的内容，即在**设置 → 安装时的默认值**中选择的版本，以及游戏尚未自行设置时您的默认预设。如果某个游戏的 NVIDIA 文件无法获取，它的模组仍会更新，界面会指出是哪个游戏。每个游戏有自己的事务，在其页面上使用“还原游戏”可全部恢复；带反作弊的游戏会被跳过。

## 检查游戏是否正常启动

游戏页面顶部的**启动游戏**会像其启动器那样启动游戏，不做任何观察。

**健康检查 → 启动并验证**会启动游戏并观察它的第一分钟：进程是否保持运行，模组是否加载，它的日志说了什么。结果是一句话（“一切正常”，或用白话说明原因），然后是各项发现：显卡和架构是否识别、驱动是否识别、模块是否被接受、Neural Rendering 是否就绪。

如果游戏在第一分钟内停止，或模组没有加载，页面会提供一键**还原**到之前的状态。同一次安装连续失败两次后，还原会成为主按钮。**准备诊断**会生成一个文本文件压缩包，其中不含您的用户名和机器名，请先阅读，再自行附到问题反馈中：Hub 不会发送任何东西。

这项验证说明游戏能启动、模组能加载。它不评判画面，也不评判性能。

## 还原

健康检查页面上的**此游戏的备份**按时间列出 Hub 的每一次操作。您可以回到某次操作之前的状态，或回到 Hub 做任何改动之前的状态（**还原游戏**）。

之后被游戏、启动器或其他工具更改过的文件绝不会被覆盖：它会保持原样并被报告。设置文件 `rtx-encore.jsonc` 是您的：如果它之后有变化，Hub 会先询问再还原。

手动放入的模组副本可以被识别，但 Hub 只对自己写入的内容保有原始备份。

## 游戏更新之后

如果游戏的更新或修复替换了安装的文件，页面会写明：**游戏更改了安装内容**。

- **重新应用**：模组缺失时重新写入，并重新写入 Hub 仍有更好副本的 NVIDIA DLL。游戏带来的更新的 DLL 会保留。
- **忘记**：保留游戏的文件原样，并不再跟踪它们。

## 调整模组

**此游戏的全部设置**通过一个按文件各部分排列的表单编辑 `rtx-encore.jsonc`。每项设置都带有说明、默认值，以及在适用时的“需要重启”。对您的显卡无效的设置会变灰并说明原因。DLSS 预设取决于游戏中的 DLL：表单只提供已安装的 DLL 支持的预设，并说明其余预设缺失的原因；例如，帧生成预设 C 只存在于 DLSS-G 310.9.16 中。注释和 Hub 不认识的键会原样保留。

在您看到更改之前不会写入任何东西。最后一次更改可以一键撤销。**此游戏的配置**把当前生效的设置按名称保存，并可一键切换回去。

## 社区配置

**社区尚未开放**：页面会这样说明，并且不会从中读取或向其发送任何内容。开放之后，它的功能如下。

- 游戏的配置**按与您机器的接近程度排序**，并说明原因：相同显卡、相同分辨率、驱动较旧……默认只显示在您这一系列显卡上制作的配置。
- **导入**会先逐个部分显示将要改变的内容。键盘快捷键只有在您要求时才会导入；诊断设置从不导入。您之前的设置会以“导入前”为名保存，并且一个按钮就能把文件恢复得与原来完全一样。
- **点赞**、**在我这里可用**和**举报**都只需一次点击，并且可以撤回。
- **发布我的配置**：机器和版本信息由 Hub 填写；您补充 DLSS 模式、光线追踪级别和备注。**所有将要发出的内容都会在发送前原样显示。** 不含文件路径、用户名或机器名：包含这些内容的备注会被拒绝。

没有账号。密钥在您的机器上生成并留在那里；您只需选择一个昵称。

## 更新模组

**设置 → RTX Encore 来源**：RTX Encore 仓库的公开发布版本（通过 SHA-256 校验），或包含模组构建的本地文件夹。在**更新**页面，**模组通道**的选择方式与 Hub 的相同：**稳定版**只提供正式版本，**候选版**还跟随预发布版本。在您做出选择之前，本身为预发布版的 Hub 会对自身和模组都跟随候选通道。该页面会说明每个游戏装有哪个版本的模组，并显示每个发布版本的说明。

## 数据、网络与隐私

Hub 把设置、下载内容、封面以及每个游戏的备份保存在 `%LOCALAPPDATA%\EncoreHub`。这个文件夹就是您的还原途径：只要还有游戏带有 Hub 的安装，就不要删除它。

Hub 会联系以下站点，无需账号，也不发送任何属于您的信息：

- GitHub：获取模组的发布版本、Hub 的发布版本以及 NVIDIA 的 DLL；
- `encore-dl.nometa.fr`：获取 Neural Rendering 的 DLL、您选择改用的可选版本，以及来源列表；
- Steam 和维基百科：查找缺失的封面，游戏标题会发送给它们。**设置 → 封面图片**可以关闭这项查找。

没有任何遥测。

## 键盘与屏幕阅读器

所有操作都可以用键盘完成。`Ctrl+F` 跳到搜索，`F5` 重新读取文件夹，`Alt+向左键` 返回。每种状态都用文字表达，而不只靠颜色。

## 遇到问题？

请提交[问题反馈](https://github.com/SilyNoMeta/rtx-encore-hub/issues/new/choose)，写明 Hub 版本、游戏、启动器、显卡、驱动以及重现问题的步骤。请在阅读后附上健康检查页面准备的诊断包。
